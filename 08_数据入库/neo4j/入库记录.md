## 三、七项完整性校验（全部通过）

| # | 校验项 | 结果 |
|---|---|---|
| **C1** | 普通食品不得有任何 CLAIMS 关系 | ✅ 0 条违规 |
| **C2** | 所有 CONTRAINDICATED_FOR 必须有 reason | ✅ 0 条缺失 |
| **C3** | 所有 Efficacy 必须在 24 项目录内或标注为营养素补充剂 | ✅ 0 条越界 |
| **C4** | 每个产品必须有用法用量 | ✅ 20/20 |
| **C5** | 每个保健食品必须有不适宜人群 | ✅ 15/15 |
| **C6** | 每个保健食品必须有适宜人群 | ✅ 15/15 |
| **C7** | 每个产品必须有别名 | ✅ 20/20 |

**这七条对应架构草案里的三条图谱纪律**：
- G1（Efficacy 只能存目录原文）→ C3 验证
- G2（禁忌必须有 reason）→ C2 验证
- G3（相似产品只存客观差异）→ SIMILAR_TO 的 `difference` 字段已按此设计

## 四、六项业务查询验证

### Q1 客户血脂偏高有哪些产品

```
康源牌鱼油软胶囊 | 保健食品
```

### Q2 【核心能力】在服抗凝药需排除哪些产品

```
康源牌鱼油软胶囊 | critical
```

**这条是最能体现图谱价值的查询**：向量检索做不了「排除禁忌」的精确逻辑，图谱一条边就能查到。

### Q3 【核心能力】肾功能不全需排除哪些

```
康源牌乳清蛋白粉
康源牌大豆分离蛋白粉
```

### Q4 【核心能力】孕妇需排除哪些

```
康源牌鱼油软胶囊
康源牌辅酶Q10软胶囊
康源牌褪黑素片
康源牌破壁灵芝孢子粉
康源牌螺旋藻片
康源牌西洋参含片
康源牌人参胶囊
康源牌灵芝孢子油软胶囊
```

**8 个产品对孕妇不适宜**——这个数量说明为什么「孕妇能吃吗」必须谨慎回答。

### Q5 口语别名能否映射到产品

| 客户说法 | 标准产品 |
|---|---|
| 鱼油 | 康源牌鱼油软胶囊 |
| 褪黑素 | 康源牌褪黑素片 |
| 蛋白粉 | 康源牌乳清蛋白粉 |
| 钙片 | 康源牌钙维生素D软胶囊 |
| 益生菌 | 康源牌益生菌粉 |

**别名的价值**：客户不会说「康源牌鱼油软胶囊」，只会说「鱼油」。没有别名层，检索会大量漏召。

### Q6 合规规则清单（10 条）

| 规则 | 级别 |
|---|---|
| 疾病治疗类禁用表述 | critical |
| 药物替代类禁用表述 | critical |
| 绝对化禁用表述 | critical |
| 承诺类禁用表述 | critical |
| 他人经验背书禁用表述 | high |
| 主动推销禁用表述（B2 模式） | critical |
| 回避推诿禁用表述（B2 模式） | high |
| 强制警示语 | required |
| 不适宜人群主动告知 | required |

**这 10 条是把 D005 的禁用词清单结构化**，可直接供 FR-026 违规宣称拦截调用。

**特别注意「回避推诿」这条**：这是 B2 补充规范的核心，禁止「这个我不清楚」「我们不聊产品」「您问医生吧」这类表述。

## 七、执行中发现的问题与处理

| # | 问题 | 处理 |
|---|---|---|
| 1 | **Neo4j HTTP API 一次事务只能提交一条语句**（管理命令后不能跟读查询） | 执行器改为按分号拆分、逐条提交 |
| 2 | 首轮只覆盖了 P001–P015 | 补脚本 02 加 P012/P013/P015 人群 |
| 3 | **15 个产品全部缺 Usage 节点**（首轮脚本漏了） | 补脚本 02 建 15 个用法节点 |
| 4 | 普通食品 P016–P020 缺用法与别名 | 补脚本 03 补齐 |
| 5 | 校验器把「查询成功但无结果」误判为失败 | 修改 `q()` 返回值语义：成功返回空列表，失败返回 None |
| 6 | shell 里双引号被转义吞掉，导致 Cypher 语法错误 | 改用 Python 文件传参，不走 shell 内联 |

## 附：常用查询速查

```cypher
-- 切换数据库（Neo4j Browser 顶部选择 jiankangshujuku）

-- 1. 总览
MATCH (n) RETURN labels(n)[0] AS 类型, count(n) AS 数量 ORDER BY 数量 DESC;

-- 2. 找产品的全部禁忌
MATCH (p:Product {product_id:'P001'})-[:CONTRAINDICATED_FOR]->(c)
RETURN p.name, c.name, c.reason, c.severity;

-- 3. 客户说"鱼油"，怎么映射
MATCH (a:Alias {name:'鱼油'})-[:ALIAS_OF]->(p) RETURN p.name, p.approval_no;

-- 4. 哪些产品是普通食品（不能说功能）
MATCH (p:Product {category:'普通食品'}) RETURN p.name, p.approval_no, p.compliance_note;

-- 5. 查全部合规规则
MATCH (r:Rule) RETURN r.name, r.level, r.patterns ORDER BY r.level;

-- 6. 排除法：某客户群体能吃什么
MATCH (p:Product)-[:CLAIMS]->(e:Efficacy)
WHERE NOT EXISTS((p)-[:CONTRAINDICATED_FOR]->(:Contraindication {contra_id:'CI_PREG'}))
  AND NOT EXISTS((p)-[:CONTRAINDICATED_FOR]->(:Contraindication {contra_id:'CI_RENAL'}))
RETURN p.name, collect(e.name) AS 功能;
```
