## 四、关键结论速查

### 4.1 系统做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 产品知识检索与问答（图谱 + 向量 + 关键词三路） | 健康方案生成 |
| 情景演练 + 判定摘要卡 | 体检报告解析 |
| 题库组卷 + 客观题自动判分 | 客户健康档案 |
| 员工管理 + 行为日志 | 疾病诊断与用药建议 |
| 三层权限（功能 / 数据 / 知识） | 自动出题、自动判定考核结论 |

### 4.2 已定的六条硬规则

| # | 规则 | 出处 |
|---|---|---|
| 1 | **B2 定义：不主动开口，但被问了必须说清楚** | B2 补充规范 |
| 2 | **`Efficacy` 节点只能存批准功能原文，不可自由填写** | 架构草案 G1 |
| 3 | **员工经验库必须清洗后入库**，否则系统会教新人违规话术 | 架构草案 R1 |
| 4 | **知识权限必须在检索层过滤**（Milvus filter），不能查完再过滤 | 架构草案 R4 |
| 5 | **系统只出摘要卡不出分**，评分由主管填 | 辅助考核评估 |
| 6 | **「大模型美化」改为「组织表达」**：不改数字、不加事实、不加强语气 | 架构草案 4.6 |
