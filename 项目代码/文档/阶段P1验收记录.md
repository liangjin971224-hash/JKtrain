### 3.1 一个必须记住的 Cypher 陷阱

`OPTIONAL MATCH` 无匹配时会返回**一行 null**，直接 `collect()` 会得到 `[None]`：

```cypher
-- ❌ 错误：普通食品没有 CLAIMS 关系时会得到 [null]
collect(DISTINCT e)

-- ✅ 正确：过滤掉 null
[x IN collect(DISTINCT e) WHERE x IS NOT NULL] AS efficacies
```

P016（普通食品）是这个问题的最佳测试用例——它的所有关系都为空。

## 4. ⚠️ 红灯抓出的三个问题（本阶段最重要产出）

### 4.1 门禁 3 误报：把「查询」当「判定」

P1 一写完，门禁 3 立刻失败：

```
[FAIL ] 门禁3 安全判定不分散  —— 1 处违规
         infrastructure\graph\neo4j_graph_adapter.py:204  def check_contraindication
```

**先判断是误报还是真违规**，不能直接改门禁。用 AST 分析 adapter 的所有方法：

| 方法 | 是否含判定分支 |
|---|---|
| `check_contraindication` | **False**（只是查数据 + 转换） |
| 其余 8 个方法 | False |

**结论：误报。** `check_contraindication` 是端口契约要求的方法，职责是「把图谱里的禁忌查出来」，
不含任何「该不该拦」「怎么表述」的判断——那些在 `domain/rules/` 与 `safety_validator.py`。

**修法**：加白名单，但**必须同时限定文件路径与方法名**。

### 4.2 ⚠️ 第一版白名单被自证测试抓出漏洞

第一版白名单只按方法名放行：

```python
PORT_CONTRACT_METHODS = frozenset({"check_contraindication"})
```

`test_gate3_catches_scattered_safety_logic` 立刻失败——它往 `application/` 注入
`def check_contraindication(...)`，结果被放行了。

**后果**：任何人只要把判定函数起名叫 `check_contraindication`，就能绕过门禁。
**这等于门禁失效**。

**修法**：白名单改为 `{文件路径: {方法名}}` 两级限定：

```python
PORT_CONTRACT_ALLOWLIST = {
    "infrastructure/graph/neo4j_graph_adapter.py": frozenset({"check_contraindication"}),
}
```

**加守门测试**：`test_port_contract_method_has_no_decision_logic`
—— 检查该方法体内不得出现 severity 相关的条件分支。
若有人真把判定逻辑塞进去，白名单的前提就不成立，测试会失败。

**加滥用测试**：`test_gate3_still_catches_other_safety_names`
—— 注入 `check_forbidden_claims`（不在白名单）必须仍被拦。

### 4.3 severity 转换是 fail-open，改成 fail-safe

初版实现遇到未知 `severity` 降级为 `medium`：

```python
except ValueError:
    return Severity.MEDIUM      # ← 危险
```

**问题**：`severity` 决定 P4 护栏是否拦截（只有 critical 无条件拦）。
若脏数据让某个禁忌的 severity 变成未知值，降成 medium 就等于**放行**。
例如向在服抗凝药的客户推荐鱼油——安全事故级别的问题。

**修法**：未知值一律降级为 **CRITICAL**（从严拦截，人工复核），并打 warning 日志。

| 场景 | fail-open（错） | fail-safe（对） |
|---|---|---|
| 数据干净 | 无差别 | 无差别 |
| 出现脏数据 | **该拦的不拦** | 多拦一条，人工复核时发现 |
| schema 变更 | 静默放行 | 立刻暴露（误拦报警） |

数据层事实：47/47 条禁忌全带 severity，取值只有 critical/high/medium。
出现未知值只可能是脏数据——此时从严才对。

        "参考答案", collection="health_training_docs", top_k=20,
