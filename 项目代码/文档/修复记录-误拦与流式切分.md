# 修复记录：同一问题两次结果不同

> ⚠️ **本阶段的遗留项可能有部分已完成** ——
> 最新汇总见 `文档/未完成事项清单.md`（2026-10-23 逐条核实过）。

> 日期：2026-10-22
> 触发：用户实测截图（问「康源牌黑芝麻丸有什么功能」两次，一次正常一次拒答）

---

## 1. 现象

同一句话问了两次：

| 次数 | 结果 |
|---|---|
| 第 1 次 | ✅ 正常回答 |
| 第 2 次 | ❌ 已拒答，内容截断在「…或疾病预防、」 |

被拦的句子是：

> 普通食品不能宣称任何保健功能或**疾病预防、治疗**功能。

**这是《广告法》原文表述，完全合规。**

---

## 2. 根因：两层问题叠加

### 2.1 规则层：否定词表靠枚举，必然漏

`_NEGATED_CLAIM` 原来只列了 `不涉及`，但真实文本是「不能**涉及**」。

逐条枚举「否定词 + 动词」的搭配，永远会漏下一种写法。

### 2.2 流式切分层（更隐蔽）：顿号被当成断句点

`StreamGuard._CLAUSE_END` 把「、」列进了切分标点，于是：

```
原文：普通食品不能宣称任何保健功能或疾病预防、治疗功能，也不能替代药物。

切成：「普通食品不能宣称任何保健功能或疾病预防、」
      「治疗功能，也不能替代药物。」
                ↑ 单独检测命中「治疗」→ 误拦
```

**这解释了「同一问题两次不同结果」**：
LLM 每次输出措辞略有不同，有的版本恰好在顿号处凑够了切分长度。
所以是**概率性复现**，不是每次都出现。

### 2.3 为什么这两个问题要一起修

只修规则层：整段检测通过了，但流式切开后第二段还是会被拦。
只修流式：非流式路径能过，但「不能涉及」这类写法仍然漏。

**两层都修才彻底。**

---

## 3. 修复内容

### 3.1 `_NEGATED_CLAIM` 改为组合式

```python
# 旧：枚举
r"(?:不用于|不具备|不具有|...|不涉及|不属于|...)"
# 新：否定前缀 × 动词
r"(?:(?:不能|不得|不可|不应|不该|并非|绝非|无|非)"
r"  (?:用于|具备|具有|含|涉及|属于|提供|声称|宣称|明示|暗示|作|有|...)?"
r"|不(?:用于|具备|具有|含|涉及|...)"   # 裸「不」只允许固定搭配
r")"
```

**为什么要限制裸「不」**：
`不可以治疗，但能缓解` 会被 `不` + 中间 + `治疗` 误判为否定陈述，
而它其实是**转折**——前半否定、后半肯定。

### 3.2 顿号从切分点移除

```python
# 旧
_CLAUSE_END = re.compile(r"[，,、：:]")
# 新
_CLAUSE_END = re.compile(r"[，,：:]")
```

**理由**：
- 顿号 = **并列**，切开会把一个概念劈成两半
- 逗号/冒号 = **分句**，切开语义仍然完整

### 3.3 新增双否/转折排除

```python
_DOUBLE_NEGATION = re.compile(
    r"(?:不可否认|不能不说|不得不说|...)[^。！？\n]{0,12}"
    r"|(?:不能|不得|不可|不应|不该)[^。！？\n，,；;]{0,12}"
    r"(?:，|,|；|;|但|但是|不过|然而|可是)[^。！？\n]{0,12}",
)
```

`_strip_negated_claims()` 的逻辑：
- 匹配到 `_NEGATED_CLAIM` 时，先看是否与双否/转折**重叠**
- 重叠 → **不挖**（留给违规规则抓）
- 不重叠 → 挖掉（否定陈述放行）

**为什么不「先挖双否再挖否定」**：
双否片段被挖掉后，里面的功效词也一起没了，违规规则就抓不到 → 反而漏放。

### 3.4 新增名词短语放行

```python
_NOUN_PHRASE = re.compile(
    # 形态一：完整并列短语「疾病预防、治疗功能」
    r"(?:疾病)?(?:预防|防止)\s*、?\s*(?:治疗|治愈)\s*(?:功能|作用|功效|宣称|宣传)?"
    # 形态二：孤立的后半段，必须带名词化标记
    r"|(?<![有具能可该])(?:治疗|治愈)\s*、?\s*(?:功能|作用|功效)"
    r"(?:\s*的\s*(?:宣称|宣传|表述|标注|描述)|\s*(?:宣称|宣传|表述|标注|描述))",
)
```

**关键区分：评价 vs 指称**

| 表述 | 性质 | 判定 |
|---|---|---|
| 治疗功能**很明显** | 在**评价**这个功能强 | ❌ 违规 |
| 治疗功能**的宣称** | 在**指称被禁止的说法本身** | ✅ 合规 |

## 4. 三轮迭代过程（都固化成测试了）

### 规则迭代

| 版本 | 做法 | 问题 |
|---|---|---|
| v1 | 否定词改成「(不能\|不) + 任意动词」 | 漏放「不可以治疗，但能缓解」 |
| v2 | 加双否排除，但**先挖掉**双否片段 | 功效词一起被挖 → 漏放 |
| **v3** | **重叠则不挖** | ✅ 正确 |

### 名词短语迭代

| 版本 | 做法 | 问题 |
|---|---|---|
| v1 | 只判「治疗+功能」 | 「该产品有治疗作用」被误放 |
| v2 | 加前置排除（有/具有/能/可） | 「这个治疗功能很明显」仍被误放 |
| **v3** | 要求必须带名词化标记 | ✅ 正确 |
