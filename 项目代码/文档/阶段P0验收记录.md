### 3.1 红灯抓出的两个真实缺陷（本阶段最重要产出）

**缺陷 1：门禁 3 漏检最常用的命名**

```python
# 原写法
r"\w*(?:contraindicated|forbidden_claim|allergen)\w*"
```

`check_contraindication()`（`contraindication`）**漏过**——而这是最常见的命名。
实测：`contraindicated` 命中、`contraindication` 漏过、`ContraindicationMatcher` 漏过。

**修法**：词根改 `contraindicat`，覆盖三种形态。`test_architecture.py` 同步修复。

> 若没有 `test_ci_gate.py` 的自证测试，这条门禁会一直显示 PASS，
> **而实际上一半的安全判定写法它都拦不住**。

**缺陷 2：文件名路径穿越**

```python
PurePosixPath("submissions") / "a" / "../../evil.pdf"
# → 'submissions/a/../../evil.pdf'   ← 不规范化 `..`
```

解析后落在 `root/evil.pdf`，**仍在 root 内**，所以「解析后是否在 root 内」这道检查拦不住，
但用户已能控制落盘目录。

**修法**：改为**输入逐个校验**（分隔符 / `..` / 盘符）→ 拼接 → 再解析兜底。
替身 `fake_filestorage.py` 同步修复（原本只查 `".." in rel.parts`，同样拦不住）。
