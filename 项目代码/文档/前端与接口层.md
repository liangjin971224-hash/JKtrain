## 4. ⚠️ 三个必须解决的工程问题

### 4.1 依赖注入必须是进程级单例

**问题**：`build_container()` 会加载 bge-m3（14 秒）+ 建 BM25 索引（1 秒）。
如果每个请求都装配，第 1 个请求等 15 秒，且每次都重复占显存。

**做法**：FastAPI 的 `lifespan` 里装配一次，全局复用。

**测试上的坑**：TestClient 进入 `with` 就会触发 lifespan → 每个测试文件多等 15 秒。
实测整组接口测试 **68 秒**。

**修法**：测试里把 `app.router.lifespan_context` 换成空函数，并注入假容器。
**68 秒 → 1.27 秒**。

### 4.2 案例目录不能由接口层直接读

**门禁拦下了**：
```
interfaces\http\routers\drill.py:53 → infrastructure.content.case_loader
```
`test_interfaces_does_not_import_infrastructure` 失败。

**门禁是对的**：接口层直接读文件会让「换实现要改路由」、「无法用假实现测接口」。

**修法**：加一层 `application/services/case_catalog.py`

```
interfaces/http/routers/drill.py
    ↓ 只 import application（允许）
application/services/case_catalog.py    ← 只接受 loader 函数，不 import 实现
    ↓ loader 由装配根注入
infrastructure/content/case_loader.py
```

**额外收获**：`CaseCatalog` 可以注入假 loader，测试完全不读磁盘。

### 4.3 503 与 500 必须区分

**问题**：注册 `Exception` 兜底处理器后，需要区分：
- **503** = 下游不可用（Neo4j / Milvus / LLM 挂了）→ 运维查服务
- **500** = 代码 bug → 开发改代码

但判断「是否基础设施异常」需要 `isinstance(exc, InfrastructureError)`，
而那就得 import infrastructure —— 又被门禁拦。

**修法**：`interfaces/http/errors.py` 里按**类名 + MRO** 判断：

```python
_INFRA_BASE_NAMES = frozenset({
    "InfrastructureError", "VectorSearchError", "LLMCallError",
    "LLMResponseFormatError", "GraphQueryError", "StorageError",
})

def is_infrastructure_error(exc) -> bool:
    return any(cls.__name__ in _INFRA_BASE_NAMES for cls in type(exc).__mro__)
```

**已知取舍**：改名会失效。已在注释里标注，并留了测试位。

**另一个坑**：注册 `Exception` 处理器后，FastAPI 自己的 404/422 也会走进来。
必须放行 `HTTPException`，否则**所有 404 都变成 500**。
