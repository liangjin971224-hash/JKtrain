# 环境说明

> 更新：2026-10-22
> 本项目用**继承式虚拟环境**，避免重复下载 2.5GB 的 torch。

---

## 1. 当前环境

| 项 | 值 |
|---|---|
| **解释器** | `D:\项目\某健康公司培训系统\项目代码\.venv\Scripts\python.exe` |
| Python | 3.11.16 |
| 基础环境 | 继承 `D:\conda\envs\langchain_env` |
| torch | 2.5.0+cu124，**CUDA 可用** |
| 建法 | `python -m venv --system-site-packages .venv` |

## 2. 在编辑器中选中它

PyCharm / VSCode 打开 **`项目代码`** 目录时，会自动发现 `.venv`。

手动指定路径：

```
D:\项目\某健康公司培训系统\项目代码\.venv\Scripts\python.exe
```

> 注意选 `Scripts\python.exe`，不是 `.venv\python.exe`（Windows 上 venv 的
> 可执行文件在 `Scripts\` 子目录里）。

## 3. ★ 判断某个包是从哪来的

这是继承式环境最容易误判的地方：**`pip list` 里能看到 torch，不代表装在本环境里**。

```bash
.venv\Scripts\python.exe -c "import torch; print(torch.__file__)"
```

| 输出路径 | 含义 |
|---|---|
| `D:\conda\envs\langchain_env\Lib\site-packages\torch\...` | **继承来的**（没装在本环境） |
| `项目代码\.venv\Lib\site-packages\torch\...` | 本环境装的 |

同理判断任何包。**升级继承来的包前必须先想清楚**——会影响 `langchain_env` 的所有使用者
（旅游出行助手、杏林大健康等项目也都用它）。

## 4. 常用命令

```bash
# 跑日常测试（跳过集成，22 秒）
.venv\Scripts\python.exe -m pytest

# 跑集成测试（连真 Neo4j / Milvus / 真 LLM，50 秒）
.venv\Scripts\python.exe -m pytest -m integration

# 启动自检
.venv\Scripts\python.exe main.py

# CI 门禁
.venv\Scripts\python.exe scripts/ci_gate.py

# 装包（装进 .venv，不影响 langchain_env）
.venv\Scripts\pip install <包名>
```

## 6. 如果要建完全独立的环境

见 `requirements-full.txt` 头部说明。代价是重下 torch（约 2.5GB）。

## 7. 已知注意点

| 项 | 说明 |
|---|---|
| `pip list` 会列出继承的包 | 想只看本环境装的：`pip list --local` |
| 升级重包要谨慎 | torch / transformers 升级会影响 `langchain_env` 的其他项目 |
| `.venv` 已加入 `.gitignore` | 约 2GB，不提交 |
| 迁移到别的机器 | 该机需要同样的 `langchain_env`，或改用 `requirements-full.txt` |
