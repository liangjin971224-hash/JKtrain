## 学习目标

学完本文档，你应当能够：

1. 准确说出保健食品与普通食品、药品的区别
2. 认出保健食品的「蓝帽子」标志与批准文号
3. 说出保健食品允许声称的保健功能范围与数量
4. 背出强制警示语原文
5. 判断一个产品是保健食品还是普通食品
6. 说出客户询问功效时的标准应答结构

## 第一章 三个概念的区别

### 1.1 一张表看懂

| 维度 | 药品 | 保健食品 | 普通食品 |
|---|---|---|---|
| **批准标识** | 国药准字 | 蓝帽子 + 国食健注/食健备 | SC 编号 |
| **能否治病** | 能（有适应证） | **不能** | 不能 |
| **能否宣称功效** | 能宣称适应证与疗效 | **只能宣称目录内的保健功能** | **不能作任何功能声称** |
| **销售场所** | 药店（处方药需处方） | 允许保健食品销售的区域 | 任何食品销售场所 |
| **监管强度** | 最严 | 严格 | 一般 |
| **典型例子** | 阿莫西林胶囊 | 鱼油软胶囊 | 蛋白固体饮料 |

### 1.2 最容易混淆的一对：保健食品 vs 普通食品

这两个最容易被搞混，因为**外观可能长得一模一样**。

**举个真实会遇到的例子**：

| | 产品 A | 产品 B |
|---|---|---|
| 名称 | XX 牌蛋白粉 | XX 牌复合蛋白固体饮料 |
| 外观 | 罐装粉剂 | 罐装粉剂 |
| 主要成分 | 乳清蛋白 | 大豆蛋白 + 乳清蛋白 |
| 批准标识 | **蓝帽子 + 食健备G2025...** | **SC11344010100123** |
| 产品类别 | **保健食品** | **普通食品** |
| 能不能说「有助于增强免疫力」 | **能**（若批件含此项） | **绝对不能** |

**记住一句话**：**看罐子没用，看批准标识。**

- 有蓝帽子 → 保健食品，可以按批件说功能
- 只有 SC 编号 → 普通食品，一个字的功能都不能说

### 1.3 为什么这个区别这么重要

因为**说错了是违法的**。

| 情形 | 后果 |
|---|---|
| 把普通食品说成有保健功能 | 违反《食品安全法》，属虚假宣传 |
| 把保健食品说成能治病 | 违反《广告法》，可能构成虚假广告 |
| 宣称产品能替代药物 | 最严重，可能导致客户延误治疗 |

**这不是「话说得好不好听」的问题，是法律责任问题。**

## 第二章 保健食品的「身份证」

### 2.1 蓝帽子标志

正规保健食品的最小销售包装上，必须印有**天蓝色的草帽形标志**，俗称「蓝帽子」。

蓝帽子下方有**批准文号**。没有蓝帽子的，**一律不是保健食品**。

### 2.2 批准文号的四种格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 国产·注册 | **国食健注 G** + 4位年代号 + 4位顺序号 | 国食健注G20250012 |
| 进口·注册 | **国食健注 J** + 4位年代号 + 4位顺序号 | 国食健注J20250008 |
| 国产·备案 | **食健备 G** + 4位年代号 + 2位省级代码 + 6位顺序号 | 食健备G202544000123 |
| 进口·备案 | **食健备 J** + 4位年代号 + 00 + 6位顺序号 | 食健备J202500000456 |

**记忆口诀**：
- **注** = 注册（走过审评审批），**备** = 备案（原料在目录内，走备案）
- **G** = 国产（Guo），**J** = 进口（Jin）
- 看到「国食健注」或「食健备」，就是保健食品

### 2.3 历史文号（客户可能拿着老包装来问）

| 时期 | 国产格式 | 进口格式 |
|---|---|---|
| 2003 年前 | 卫食健字（年号）第 xxx 号 | 卫进食健字 / 卫食健进字 |
| 2003–2016 | 国食健字 G + 8位 | 国食健字 J + 8位 |
| **2016 至今** | 国食健注 G / 食健备 G | 国食健注 J / 食健备 J |

**遇到「卫食健字」的老包装**：不是假货，是 2003 年前批准的，仍在有效期内可以销售。但不要主动推荐，因为配方和功能声称可能已不符合现行目录。

### 2.4 怎么帮客户核实真伪

如果客户怀疑产品真假，你应当告诉他核实方法，而不是只说「我们肯定是真的」：

1. 登录**国家市场监督管理总局**官网
2. 进入「服务」→「特殊食品信息查询」
3. 输入批准文号
4. 核对：产品名称、生产企业、适宜人群、功效成分是否与包装一致

**这个动作本身就是专业性的体现。** 敢让客户去查，比说一百句「保证正品」都有用。

## 第三章 允许声称的保健功能

### 3.1 只能在这 24 项里说

国家对保健食品的保健功能实行**目录管理**。目前允许声称的保健功能共 **24 项**（非营养素补充剂）。

| 序号 | 允许声称的功能（原文） |
|---|---|
| 1 | 有助于增强免疫力 |
| 2 | 有助于抗氧化 |
| 3 | 辅助改善记忆 |
| 4 | 缓解视觉疲劳 |
| 5 | 清咽润喉 |
| 6 | 有助于改善睡眠 |
| 7 | 缓解体力疲劳 |
| 8 | 耐缺氧 |
| 9 | 有助于控制体内脂肪 |
| 10 | 有助于改善骨密度 |
| 11 | 改善缺铁性贫血 |
| 12 | 有助于改善痤疮 |
| 13 | 有助于改善黄褐斑 |
| 14 | 有助于改善皮肤水份状况 |
| 15 | 有助于调节肠道菌群 |
| 16 | 有助于消化 |
| 17 | 有助于润肠通便 |
| 18 | 辅助保护胃粘膜 |
| 19 | 有助于维持血脂（胆固醇/甘油三酯）健康水平 |
| 20 | 有助于维持血糖健康水平 |
| 21 | 有助于维持血压健康水平 |
| 22 | 对化学性肝损伤有辅助保护作用 |
| 23 | 对电离辐射危害有辅助保护作用 |
| 24 | 有助于排铅 |

> 注：另有 2026 年 1 月 1 日起新增的「有助于维持骨关节健康（缓解疼痛或僵硬/缓解软骨损伤）」，公司应关注最新公告。

### 3.2 超出这 24 项，一个字都不能说

**这是红线，没有例外。**

不管：
- 客户自己说的
- 老员工教的
- 网上查到的
- 产品确实是这个作用

**只要不在 24 项目录里，就不能作为保健功能声称说出口。**

### 3.3 必须一字不差地说原文

| 错误说法 | 正确说法 | 错在哪 |
|---|---|---|
| 降血糖 | 有助于维持血糖健康水平 | 用了医疗术语 |
| 降血脂 | 有助于维持血脂健康水平 | 用了医疗术语 |
| 降血压 | 有助于维持血压健康水平 | 用了医疗术语 |
| 增强免疫力 | **有助于**增强免疫力 | 少了「有助于」，变成绝对效果 |
| 改善睡眠 | **有助于**改善睡眠 | 同上 |
| 减肥 | 有助于控制体内脂肪 | 「减肥」是旧称 |
| 增加骨密度 | 有助于改善骨密度 | 「增加」是旧称 |

**为什么「有助于」三个字不能省**：
- 「有助于」= 有辅助作用，不保证结果
- 「增强免疫力」= 确保效果，是绝对化表述

**一字之差，性质不同。**

## 第四章 强制警示语

### 4.1 必须说的那句话

> **保健食品不是药物，不能代替药物治疗疾病**

这是国家强制要求所有保健食品必须标注的警示语，**不可省略、不可改写**。

### 4.2 什么时候必须说

| 场景 | 是否必须说 |
|---|---|
| 客户主动问产品功效 | **必须说** |
| 你主动介绍保健食品 | **必须说** |
| 客户问能不能治病 | **必须说**，且要说明不能 |
| 客户问能不能代替药 | **必须说**，且要明确否定 |
| 客户只问价格、规格 | 建议说 |
| 客户问普通食品 | 不需要（但也不能说功能） |

### 4.3 除此之外还要主动说的三件事

| # | 必须主动说明 | 为什么 |
|---|---|---|
| 1 | 这是保健食品还是普通食品 | 客户有权知道买的是什么 |
| 2 | **不适宜人群范围** | 涉及安全，客户属于相关人群必须提示 |
| 3 | 每日食用量上限 | 超量有风险 |

**第 2 条最容易漏。** 客户说「我给我妈买的」，你就必须问一句「阿姨有没有在吃什么药」，然后查这款产品的不适宜人群。

## 第五章 各品类产品的核心禁忌（必须背下来）

以下是公司主要产品线的高危禁忌，**这些必须背熟，不能查资料现说**。

### 5.1 鱼油类

| 项 | 内容 |
|---|---|
| 适宜人群 | 血脂偏高者 |
| **高危不适宜人群** | **出血倾向者、出血性疾病患者**、肝功能不全者、少年儿童、孕妇、乳母 |
| **特别提示** | **对海产品过敏者不推荐食用** |
| **最危险的场景** | 客户说「我在吃阿司匹林 / 华法林」→ **必须提示咨询医生** |

**为什么危险**：鱼油可能影响凝血功能，与抗凝药同服有出血风险。

### 5.2 褪黑素类

| 项 | 内容 |
|---|---|
| 适宜人群 | 成人 |
| 不适宜人群 | 少年儿童、孕妇、乳母 |
| **特别提示** | **从事驾驶、机械作业或危险操作者，不要在操作前或操作中食用** |
| **另一提示** | 自身免疫症（类风湿等）及甲亢患者慎用 |
| **最危险的场景** | 客户问「我开车能吃吗」→ **明确说不建议** |

### 5.3 蛋白粉类（乳清蛋白 / 大豆分离蛋白）

| 项 | 内容 |
|---|---|
| 适宜人群 | 因蛋白质摄入不足而致免疫低下的成人 |
| 不适宜人群 | 少年儿童 |
| **特别提示** | **肾功能不全者慎用**；**无明显缺乏蛋白质的人群不推荐食用** |
| **过敏提示** | 植物蛋白过敏者不宜用大豆蛋白；动物蛋白过敏者不宜用乳清蛋白 |
| **最危险的场景** | 客户说「我肾不好」→ **建议咨询医生，不给具体用量** |

### 5.4 人参、西洋参类

| 项 | 内容 |
|---|---|
| 适宜人群 | 易疲劳者、免疫力低下者 |
| 不适宜人群 | 少年儿童、孕妇、乳母；**人参另忌湿热体质、阴虚体质** |
| **配伍禁忌** | **不宜与含藜芦、五灵脂的中草药同用**（人参）；西洋参忌藜芦 |
| **其他提示** | 感冒、舌苔厚腻、易上火者不推荐使用 |
| **最危险的场景** | 客户说「我在吃中药」→ **必须问清是什么中药** |

### 5.5 一张速查表（建议打印贴在工位）

| 客户说了什么 | 你该做什么 |
|---|---|
| 我在吃阿司匹林 / 华法林 / 抗凝药 | 提示鱼油类需咨询医生 |
| 我要开车 / 做危险操作 | 提示褪黑素类不建议 |
| 我肾功能不好 | 蛋白粉类建议咨询医生，不给用量 |
| 我在吃中药 | 问清具体药材，查是否含藜芦、五灵脂 |
| 我对海鲜过敏 | 鱼油类不推荐 |
| 我怀孕了 / 在哺乳 | 绝大多数产品不适宜，建议咨询医生 |
| 我给孩子买 | 绝大多数产品不适宜儿童，先查说明书 |

## 第六章 客户问功效时的标准应答

### 6.1 四句式结构

```
① 说明身份：这是保健食品 / 普通食品
② 说清功能：批准的功能原文是"……"
③ 划清边界：不是药物，不能代替药物治疗疾病
④ 回到方案：结合你的情况，饮食/生活方式上可以这样调整……
```

### 6.2 三个标准范例

**范例一：客户问「这个能降血糖吗」**

> 这是保健食品。它批准的功能是「有助于维持血糖健康水平」。需要说明的是，它不是药物，不能代替药物治疗疾病。
> 如果您现在在用降糖药，用药一定要听医生的，不能自己停或减。
> 我能帮您的是饮食方面，比如主食粗细搭配、控制精制糖摄入，这些对血糖管理更直接。

**范例二：客户问「吃了能停降压药吗」**

> 不可以。
> 这个产品是保健食品，不是药物，不能代替药物治疗疾病，更不能替代您的降压药。
> 是否调整用药、怎么调整，必须由医生根据您的血压监测情况决定，我这边不能给任何用药建议。
> 如果您想辅助管理，我可以在饮食和生活方式上给您一些建议，比如控制钠摄入、规律监测血压。但药一定不能自己停。

**范例三：客户问「你们有保健品吗」（客户主动问）**

> 有的，我们有 X 款，分别是……
> 不过我想先了解一下您的情况，这样能帮您看哪款更合适。
> 需要说明的是，这些都是保健食品，不是药物，不能代替药物治疗疾病。

### 6.3 六个绝不能说

| # | 绝不能说 | 为什么 |
|---|---|---|
| 1 | 「有改善作用」 | 疾病治疗/改善宣称 |
| 2 | 「可以试试停药」 | 最严重，可能致害 |
| 3 | 「老年人吃了更好」 | 人群功效宣称 |
| 4 | 「这个成分抗炎」 | 疾病相关暗示 |
| 5 | 「比药还管用」 | 替代药物宣称 |
| 6 | 「保证有效，无效退款」 | 虚假承诺 |

### 6.4 一个容易忽略的点：不能回避

客户问了产品，**你必须如实回答**，不能因为怕说错就说「这个我不清楚」「您问医生吧」。

**正确做法**：
- 产品客观信息（成分、规格、用法、不适宜人群）→ **必须答**
- 超出产品信息的医学判断（"这个对我的肾病有没有影响"）→ **可以说「这个需要医生判断」**

**界线**：**说明书上有的，必须答；说明书上没有的，可以说需要医生判断。**

## 第七章 自测题

**1. 以下哪个是保健食品的批准文号？**
A. 国药准字H20250001
B. 食健备G202544000123
C. SC11344010100123
D. 国食注字YP20250001

**2. 「有助于维持血糖健康水平」和「降血糖」的区别是什么？**

**3. 客户说「我在吃阿司匹林，能吃鱼油吗」，你怎么回答？**

**4. 强制警示语的完整原文是什么？**

**5. 客户问「这个产品对我妈的骨质疏松有用吗」，你怎么回答？**

---

### 参考答案

**1. B**
- A 是药品
- C 是普通食品（食品生产许可证）
- D 是婴幼儿配方乳粉

**2.**
- 「有助于维持血糖健康水平」是目录内的合法保健功能声称，表述为辅助作用
- 「降血糖」是医疗术语，暗示治疗作用，属违规表述
- 关键差别：「有助于」表示辅助，不保证结果

**3.**
示例回答：
> 鱼油的不适宜人群里包括出血倾向者和出血性疾病患者。阿司匹林有抗凝作用，两者同服可能增加出血风险。
> 这种情况建议您先咨询医生，让医生判断能不能吃、怎么吃。
> 我这边不能给用药相关的建议。

**4.**
保健食品不是药物，不能代替药物治疗疾病。

**5.**
示例回答：
> 这款产品批准的功能是「有助于改善骨密度」，是保健食品，不是药物，不能代替药物治疗疾病。
> 阿姨的情况建议先由医生评估，特别是如果需要用药，一定要遵医嘱。
> 饮食上可以关注钙和维生素D的摄入，比如奶制品、豆制品，这些是骨健康的基础。

## 附录：常见错误对照

| 错误说法 | 问题 | 正确说法 |
|---|---|---|
| 这个能降三高 | 医疗术语 + 夸大 | 这款批准的功能是「有助于维持血脂健康水平」；三高需要遵医嘱管理 |
| 吃这个不用吃药了 | 替代药物，最严重 | 不能代替药物，用药必须遵医嘱 |
| 我们这个是纯天然的，没副作用 | 绝对化 + 暗示安全 | 保健食品有适宜人群和用量要求，请按说明书食用 |
| 很多人都说吃了有效 | 以他人经验背书 | 个体差异较大，我不能承诺具体效果 |
| 这个是医院同款 | 权威暗示（无依据） | 这款是保健食品，批准文号是……，您可以到市场监管总局官网核实 |
| 你先带两盒试试 | 主动推销 | （不该说）如需购买客户会主动提出 |
