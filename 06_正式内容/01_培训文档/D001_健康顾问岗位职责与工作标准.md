## 学习目标

学完本文档，你应当能够：

1. 说清健康顾问这个岗位的三项核心职责
2. 说清这个岗位**不做什么**（边界）
3. 说出一次完整服务的五个环节
4. 判断哪些事必须请示主管
5. 说出违反边界的三种后果

---

## 第一章 这个岗位是什么

### 1.1 一句话定义

> 健康顾问是**客户健康需求与公司服务、产品之间的翻译者**。
> 你的价值不在于卖出多少，而在于**让客户听懂、选对、用得安全**。

### 1.2 三个关键词

| 关键词 | 含义 | 反面 |
|---|---|---|
| **专业** | 说得准、说得出依据 | 靠感觉、凭经验、听人说 |
| **合规** | 知道哪些话不能说 | 为了成交什么都敢说 |
| **有边界** | 知道哪些事不该你做 | 什么都敢接、什么都敢答 |

### 1.3 岗位的核心矛盾（必须理解）

你的工作天然存在一个张力：

> 一方面，公司需要业绩，你也有销售任务；
> 另一方面，专业顾问的价值恰恰体现在**敢说"你不需要"**。

**这个矛盾怎么处理？**

答案不是"不做销售"，而是**顺序不能反**：

```
正确的顺序：了解需求 → 判断是否真的需要 → 如实告知 → 客户自主决定
错误的顺序：先想好要卖什么 → 找理由说服 → 成交
```

**为什么这个顺序重要**：客户的信任只有一次。为了成交说了一句不该说的话，可能失去一个长期客户，甚至带来法律风险。

**公司对这个岗位的定位**：我们要的是能长期做下去的顾问，不是一次性的销售。

## 第二章 三项核心职责

### 2.1 职责一：解答客户疑问

| 客户会问什么 | 你怎么答 |
|---|---|
| 你们有这个产品吗 | 明确说有 / 没有，报产品名 |
| 这个含什么成分 | 报配料表和标志性成分含量 |
| 这个吃了有什么用 | **只能报批准功能原文**，并加警示语 |
| 什么人不能吃 | 完整报不适宜人群和注意事项 |
| 怎么吃 | 报食用方法和每日用量上限 |
| 能不能和别的产品一起吃 | 查配伍禁忌，不确定的建议咨询专业人员 |

**第一条铁律**：**客户主动问了产品，必须如实回答，不能回避。**

回避不是谨慎，是失职。客户问"你们有鱼油吗"，你说"这个我不太清楚"，客户不会觉得你专业，只会觉得这家公司的人什么都不懂。

### 2.2 职责二：识别客户真实需求

客户嘴上说的，往往不是他真正需要的。

| 客户说的 | 可能真正的需求 | 你要做什么 |
|---|---|---|
| 我想买点补钙的 | 可能是体检发现骨密度低 | 先问清楚是什么情况发现的 |
| 我朋友吃这个挺好 | 想找人帮他判断适不适合自己 | 说明个体差异，问清他的情况 |
| 我睡眠不好 | 可能同时有焦虑、作息问题 | 不问病，但可以问作息习惯 |
| 我要减肥 | 可能真正想要的是体型改善 | 了解目标和现状，不承诺效果 |

**关键动作**：**先问，再答。** 不了解情况就给建议，是最容易出错的做法。

### 2.3 职责三：引导到正确的解决方案

解决方案有三种，**优先级从高到低**：

| 优先级 | 方案 | 什么时候用 |
|---|---|---|
| **1** | **生活方式调整** | 绝大多数情况的第一选择 |
| **2** | **公司服务**（检测、评估、跟踪） | 需要持续管理的情况 |
| **3** | **产品** | 前两者不足，且客户有明确需求时 |

**这个顺序不能乱。** 举个最典型的例子：

客户说"我想补钙"——

```
错误的做法：直接推荐钙片
正确的做法：先问"您平时喝奶吗？每天大概多少？"
           → 如果每天喝 300ml 奶，其实钙已经够了
           → 如果几乎不喝奶，先建议增加奶制品
           → 如果乳糖不耐受或确实摄入不足，再谈补充剂
```

**先想到食物，再想到产品。** 这是专业顾问和推销员的分界线。

## 第三章 边界：这个岗位不做什么

这一章比前两章都重要。**知道边界的人，才能长期做下去。**

### 3.1 五条绝对不能越的线

| # | 不做 | 为什么 | 遇到时怎么办 |
|---|---|---|---|
| **1** | **不诊断** | 诊断是执业医师的行为 | 「这个需要医生判断」 |
| **2** | **不建议用药、不建议停药** | 用药调整是医生的职责 | 「用药一定要听医生的」 |
| **3** | **不解读体检报告结论** | 报告解读属医疗行为 | 「建议您带报告去医院复查」 |
| **4** | **不预测疗效、不承诺效果** | 个体差异大，承诺即虚假 | 「个体差异较大，我不能承诺」 |
| **5** | **不替客户判断"能不能吃"** | 只能陈述人群范围 | 「不适宜人群是……您属于吗？」 |

### 3.2 五个必答问题（客户最常问，也是最容易越界的）

**问：这个能治我的病吗？**

> ❌ 不能这样说：「有改善作用」「很多人吃了就好了」「对这个病有帮助」
> ✅ 正确说法：「这是保健食品，不是药物，不能治疗疾病。它批准的功能是『……』。」

**问：吃了能停药吗？**

> ❌ 绝不能有任何模糊：「可以试试」「慢慢减」「看情况」
> ✅ 必须明确：「**不可以**。用药调整必须由医生决定，不能自己停。」

**问：我这个情况适合吃吗？**

> ❌ 不能说：「可以吃」「你这个正好适合」
> ✅ 正确说法：「这款的不适宜人群是……如果您不属于，可以按说明食用；如果属于，建议先咨询医生。」

**问：要吃多久见效？**

> ❌ 不能说：「一个月」「三个疗程」「很快」
> ✅ 正确说法：「保健食品是长期调理，不是药物，没有固定的见效时间，也不能承诺效果。」

**问：有没有副作用？**

> ❌ 不能说：「纯天然的，没有副作用」
> ✅ 正确说法：「按说明书用量食用是安全的。但有明确的不适宜人群和用量上限，超过用量或者属于不适宜人群，就不建议食用。」

### 3.3 遇到这些情况，必须请示主管

| 情况 | 为什么 |
|---|---|
| 客户明确说要投诉 | 需要主管介入处理 |
| 客户要求退款 / 退换货 | 按售后流程走，不由你决定 |
| 客户说吃了产品身体不适 | **必须记录并上报，不能自行解释** |
| 客户询问公司资质、工商信息 | 由主管或官方渠道答复 |
| 客户要求你出具任何书面承诺 | 你不能代表公司承诺 |
| 客户在店内出现身体不适 | **立即拨打 120 + 通知店长** |

**最后一条特别重要**：客户在店内出现胸闷、晕倒、面色苍白等情况，**不要判断、不要处置、不要给任何东西吃**，立即呼叫急救。

## 第四章 一次完整服务的五个环节

### 4.1 五环节总览

| 环节 | 时长 | 核心动作 | 关键产出 |
|---|---|---|---|
| **1 迎宾** | 1–3 分钟 | 问候、了解来访目的 | 知道客户为什么来 |
| **2 需求了解** | 5–8 分钟 | 问清关注点、用药、过敏 | 知道客户什么情况 |
| **3 方案说明** | 10–15 分钟 | 说明服务/产品信息 | 客户听懂 |
| **4 异议处理** | 视情况 | 倾听、如实回应 | 客户疑虑消除 |
| **5 记录跟进** | 3–5 分钟 | 填写记录、说明后续 | 有据可查 |

### 4.2 每一环节的关键动作

**环节 1 迎宾**

- 主动问候，不要等客户开口
- 问一句"您是第一次来吗"——决定后续话术
- 观察状态：如果客户看起来不适，先问需不需要帮助

**环节 2 需求了解（最重要）**

必须问到的四件事：

| 必问 | 为什么 |
|---|---|
| 主要关注什么 | 决定后续方向 |
| **是否在服药** | 直接影响安全 |
| **有无食物过敏** | 直接影响安全 |
| 平时的作息、饮食、运动 | 决定建议的可行性 |

**环节 3 方案说明**

如果涉及产品，必须说全五件事：

1. 产品类别（保健食品 / 普通食品）
2. 成分与**批准功能原文**
3. **不适宜人群**
4. 食用方法与用量
5. **「保健食品不是药物，不能代替药物治疗疾病」**

**环节 4 异议处理**

| 客户说 | 你的正确反应 |
|---|---|
| 太贵了 | 说明规格与日均成本，**不贬低竞品** |
| 我朋友说吃了没用 | 说明个体差异，**不承诺效果** |
| 你们是不是骗人的 | 出示批准文号，告知官网可查 |
| 别家更便宜 | 陈述自身客观参数，**不做比较** |

**环节 5 记录跟进**

- 按规范填写客户记录（**自述内容要标注"自述"**）
- 说明后续怎么联系
- **不强推、不催促成交**

## 第五章 工作标准与红线

### 5.1 日常工作要求

| 项 | 标准 |
|---|---|
| 仪容仪表 | 工装整洁、佩戴工牌 |
| 到岗时间 | 提前 10 分钟，完成交接 |
| 客户记录 | 当天完成，不留空白项 |
| 产品知识 | 主推产品参数必须脱稿说清 |
| 每日复盘 | 记录当天遇到的疑难问题 |

### 5.2 五条禁令（违反即处理）

| # | 禁令 | 后果 |
|---|---|---|
| 1 | 宣称产品能治病、能替代药物 | **严重违纪，可能承担法律责任** |
| 2 | 替客户判断疾病、解读体检报告结论 | 严重违纪 |
| 3 | 以免费检测、义诊为名诱导消费 | 严重违纪 |
| 4 | 泄露客户健康信息 | 严重违纪 |
| 5 | 私自承诺退款、赠品、疗效 | 视情况处理 |

### 5.3 三种后果等级

| 等级 | 情形 | 处理 |
|---|---|---|
| **一般违规** | 表述不规范、漏说不适宜人群、记录不完整 | 提醒 + 补训 |
| **严重违规** | 功效暗示、主动推销、回避客户提问 | 停岗培训 + 考核 |
| **重大违规** | 宣称治病、建议停药、替客户判断疾病 | 按公司制度处理，可能涉及法律责任 |

## 第六章 自测题

**1. 客户问「你们这个能降血糖吗」，以下哪个回答是正确的？**

A. 能，很多人吃了血糖都降了
B. 这个我不太清楚，您问医生吧
C. 这是保健食品，批准的功能是「有助于维持血糖健康水平」，不是药物，不能代替药物治疗疾病
D. 这个对血糖有帮助，您可以试试

**2. 客户说「我在吃降压药，能吃这个鱼油吗」，你应该？**

**3. 客户说「我想补钙」，你的第一步应该做什么？**

**4. 客户在店里突然说胸闷、脸色发白，你应该首先做什么？**

**5. 以下哪些情况必须请示主管？（多选）**
A. 客户明确说要投诉
B. 客户问产品含什么成分
C. 客户说吃了产品身体不适
D. 客户要求退款
E. 客户问路

---

### 参考答案

**1. C**

A 是违规宣称 + 他人经验背书；B 是回避（客户问产品，必须答）；D 是"试试"式暗示，且"有帮助"仍属功效暗示。

**2.**

> 这款鱼油的不适宜人群里包括出血倾向者和出血性疾病患者。如果您在服用抗凝类药物，两者同服可能增加出血风险。
> 这种情况建议您先咨询医生，让医生判断能不能吃。
> 我这边不能给用药相关的建议。

**3. 先问，不要直接推荐。**

> 先确认钙的摄入现状：平时喝奶吗？每天大概多少？有没有乳糖不耐受？
> 如果饮食已经能满足，就不需要额外补充；如果确实不足，先建议增加奶制品、豆制品，再考虑补充剂。

**4. 立即让客户坐下休息，同时拨打 120，并通知店长。**

**不要**判断是不是心脏问题，**不要**建议吃什么药，**不要**先观察一会儿。

**5. A、C、D**

B 是正常工作内容（必须答）；E 与工作无关。A、C、D 都涉及公司责任或客户安全，必须主管介入。
