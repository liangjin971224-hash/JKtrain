# D013 退换货与售后处理流程

> **文档编号**：D013 ｜ **类别**：业务流程 ｜ **权限**：内部
> **目标读者**：新入职健康顾问 ｜ **预计字数**：约 2,200 字
> **版本**：V1.0 ｜ **编制日期**：2026-10-21
> **审核重点**：退换条件是否符合公司政策、权限划分是否清晰
> **合规提示**：**保健品不得以"无效退款"作功效承诺**

---

## 学习目标

学完本文档，你应当能够：

1. 说清哪些情况可退换、哪些不可以
2. 说出你能直接处理和必须上报的界线
3. 正确处理"吃了没效果"要求退货的情况
4. 说出"无效退款"为什么不能承诺

---

## 第一章 三个基本原则

### 1.1 三条原则

| # | 原则 | 说明 |
|---|---|---|
| **1** | **依法依规** | 符合《消费者权益保护法》和公司政策 |
| **2** | **权限清晰** | 超过你权限的，一律上报，不自行承诺 |
| **3** | **不当场承诺** | 涉及退款金额、责任认定，必须由主管确认 |

### 1.2 最重要的一条

> **你没有承诺退款的权限。**

| 你能做的 | 你不能做的 |
|---|---|
| 受理诉求、记录情况 | 承诺"可以退" |
| 解释退换政策 | 承诺退多少钱 |
| 提交申请给主管 | 承诺"几天内到账" |
| 安抚客户情绪 | 承认"是我们的问题" |

**为什么**：一旦你承诺了，公司就必须兑现，即使是超出政策的要求。

## 第二章 退换货情形分类

### 2.1 可以退换的情形

| # | 情形 | 条件 | 处理 |
|---|---|---|---|
| **1** | **商品质量问题** | 变质、异味、包装破损、超出保质期 | ✅ **无条件退换** |
| **2** | **商品与描述不符** | 收到的产品与购买时的说明不一致 | ✅ 可退换 |
| **3** | **7 天无理由** | 未开封、包装完好、不影响二次销售 | ✅ 按公司政策 |
| **4** | **发错货 / 漏发** | 产品型号或数量与订单不符 | ✅ 立即补发或退换 |
| **5** | **食用后出现不适** | **必须记录并上报，由主管判断** | ⚠️ **不当场答复** |

**第 5 条要特别注意**：客户说"吃了之后不舒服"，涉及健康安全，**不是普通的退换货问题**。

### 2.2 不可以退换的情形

| # | 情形 | 理由 |
|---|---|---|
| 1 | 已开封且非质量问题 | 影响二次销售，且涉及食品安全 |
| 2 | 超过 7 天且非质量问题 | 超出无理由退换期 |
| 3 | **"吃了没效果"** | **保健食品不能承诺效果，效果不构成退货理由** |
| 4 | 客户自己保存不当导致变质 | 非商品本身问题 |
| 5 | 促销赠品单独退换 | 按促销规则处理 |

### 2.3 关于第 3 条的详细说明

**这是退换货处理中最常见、也最容易出错的情况。**

**客户说**：「我吃了两个月，一点效果都没有，我要退货。」

**❌ 错误处理**：

> 「确实没效果的话可以退的」——**这是承诺，且暗示了效果承诺**
> 「您再吃一个月看看，还不行就退」——**变相的效果承诺**

**✅ 正确处理**：

> 「我理解您的心情，花了钱没看到变化确实让人失望。
> 不过我需要先说明：保健食品的作用是辅助调节，不是药物，本身就不能承诺具体效果，所以『没效果』在政策上不构成退换的理由。
> 但我可以帮您做几件事：
> 一是记录您的情况，反馈给公司；
> 二是如果产品还有剩余且包装完好，我可以帮您申请，看是否符合公司的其他退换条件；
> 三是如果您想换个方向，我可以帮您看看有没有更适合的方式。
> 具体能不能退，我需要提交给主管确认，不能当场答复您。」

**这个处理的关键**：
1. **不承诺**（不能说"可以退"）
2. **说清政策依据**（效果不构成理由，这是客观规定）
3. **不空手**（记录、申请、给替代方案）
4. **明确上报**（不能当场答复）

## 第三章 标准处理流程

### 3.1 五步流程

```
① 倾听与记录
   → 让客户说完，记录诉求原文
        ↓
② 判断类型
   → 质量问题？描述不符？无理由？食用不适？
        ↓
③ 说明政策
   → 告知适用条款，不承诺结果
        ↓
④ 提交上报
   → 填申请单，交主管
        ↓
⑤ 回复客户
   → 按主管意见答复，不自行加码
```

### 3.2 每一步的关键动作

**第①步：倾听与记录**

| 要记录 | 示例 |
|---|---|
| 购买时间 | 2026-09-15 |
| 产品与数量 | P001 鱼油 × 1 瓶 |
| 是否开封 | 已开封，剩余约 1/3 |
| 客户诉求 | 要求退货退款 |
| 客户理由（**原文**） | 「吃了两个月一点效果都没有」 |
| 客户情绪 | 比较激动，反复说"你们这是骗人" |

**第②步：判断类型**

按第二章的分类快速判断，特别注意区分：

| | 普通退换 | **食用后不适** |
|---|---|---|
| 性质 | 商品问题 | **健康安全问题** |
| 处理 | 按退换政策 | **立即上报，不走普通流程** |

**第③步：说明政策**

**话术模板**：

> 「我给您说一下我们的退换政策：
> 如果是商品质量问题，比如变质、包装破损，是可以无条件退换的；
> 如果是 7 天内未开封，也可以按无理由退换；
> 您这个情况是已经开封了，而且属于使用后的效果问题，按政策需要提交审核。
> 我先把您的情况记录下来，提交给主管，有结果我第一时间通知您。」

**第④步：提交上报**

| 必填项 | 说明 |
|---|---|
| 客户信息 | 编号、联系方式 |
| 购买信息 | 时间、产品、数量、金额 |
| 诉求 | 客户要什么 |
| 理由 | **客户原话** |
| 你的判断 | 属哪类情形 |
| 附件 | 购物凭证、产品照片 |

**第⑤步：回复客户**

- 按主管意见答复
- **不自行加码**（主管说退 50%，你不能说退全款）
- 记录答复内容与时间

## 第四章 三种特殊情况的处理

### 4.1 情况一：客户说吃了身体不适

**这是最高优先级的情况。**

| 步骤 | 动作 |
|---|---|
| **1** | **先问身体状况**：「您现在身体怎么样？有没有去医院？」 |
| **2** | **建议就医**（如果客户说有明显不适） |
| **3** | **立即上报主管**，不走普通退换流程 |
| **4** | 详细记录：吃了多少、吃了多久、什么症状、什么时候开始 |
| **5** | 保留剩余产品和包装（**不要销毁**） |

**绝对不能做**：

| ❌ | 为什么 |
|---|---|
| 「这个不会有什么问题的」 | 否认客户体验 |
| 「您是不是吃别的吃坏了」 | 质疑客户，且推卸责任 |
| 「您先停了再看看」 | 隐含"是产品问题"的判断 |
| 自行判断"是巧合" | 你无权判断因果关系 |

**正确话术**：

> 「您先别着急，我想先了解一下情况：
> 您是什么时候开始吃的？每天吃多少？症状是什么时候开始的？
> 您现在身体感觉怎么样？如果明显不舒服，建议您先去医院看一下。
> 这个情况我需要马上跟公司反馈，我会记录详细情况，稍后给您答复。
> 剩下的产品和包装麻烦您先保留，可能需要核对。」

### 4.2 情况二：客户情绪激动、要求当场退款

**处理**：

```
① 请到安静区域（避免影响其他客户）
        ↓
② 倾听，不打断、不辩解
        ↓
③ 明确说明："我不能当场答复，需要主管确认"
        ↓
④ 立即请主管介入
        ↓
⑤ 记录客户诉求原文
```

**❌ 不能做**：

| ❌ | 为什么 |
|---|---|
| 「我给您退，您别吵了」 | 越权承诺 |
| 「这不是我们的问题」 | 直接对抗 |
| 「您先冷静一下」 | 容易被理解为不耐烦 |

### 4.3 情况三：客户威胁投诉/曝光

**处理**：

> 「您的诉求我记下来了。我这边没有权限处理，我现在就请主管过来。
> 如果最终处理结果您不满意，您通过正规渠道反映情况是您的权利，我们配合。」

**关键**：
- **不因威胁而加码**（越威胁越让步，会形成恶性循环）
- **不阻止客户投诉**（阻止是违规的）
- **立即升级**（这种事不该由你处理）

## 第五章 关于"无效退款"

### 5.1 为什么不能承诺

**"无效退款"针对功效时，属于效果承诺，是违规的。**

| 说法 | 问题 |
|---|---|
| 「吃了没效果就退款」 | **变相效果承诺** |
| 「保证有效，无效退款」 | 直接的效果承诺 + 绝对化 |
| 「我们承诺无效退款」 | 同上 |

**法规依据**：保健食品不能宣称或暗示治疗效果，"无效退款"暗示了"应该有效"，构成效果承诺。

### 5.2 什么情况可以说"退款"

| 情形 | 能否说 |
|---|---|
| 质量问题退款 | ✅ 可以说（这是商品责任，不是效果承诺） |
| 7 天无理由退款 | ✅ 可以说（这是法定权利） |
| **"吃了没效果"退款** | ❌ **不能承诺** |
| "保证有效否则退款" | ❌ **绝对不能** |

### 5.3 标准话术对比

**❌ 错误**：
> 「我们的产品是无效退款的，您放心买。」

**✅ 正确**：
> 「我们有 7 天无理由退换的政策，条件是未开封、包装完好。
> 需要说明的是，保健食品的作用是辅助调节，不能承诺效果，所以如果是使用后觉得没效果，这个不属于退换范围。
> 您如果想先试试，可以先买小规格的。」

**这个回答的价值**：
1. 说了退换政策（透明）
2. 说了限制条件（诚实）
3. 给了降低风险的建议（小规格试用）

## 第六章 自测题

**1. 以下哪些情形可以退换？（多选）**
A. 产品包装破损
B. 已开封，客户说"吃了没效果"
C. 客户收到后发现是错误型号
D. 客户买了 3 天，未开封
E. 客户吃了之后出现皮疹

**2. 客户说「我吃了两个月一点效果都没有，要退货」，你该怎么回应？**

**3. 客户在店里大声要求退款，情绪激动，你首先应该做什么？**

**4. 客户说「吃了之后心慌」，你应该怎么处理？哪些话不能说？**

**5. 「无效退款」为什么不能承诺？**

---

### 参考答案

**1. A、C、D、E**

- A 可退换（质量问题）
- **B 不可**（已开封 + 效果问题，效果不构成退换理由）
- C 可退换（发错货）
- D 可退换（7 天无理由，未开封）
- **E 特殊处理**：可以退，但**同时必须上报**，因为涉及健康安全

**2.**

> 我理解您的心情，花了钱没看到变化确实让人失望。
> 不过我需要先说明：保健食品的作用是辅助调节，不是药物，本身就不能承诺具体效果，所以"没效果"在政策上不构成退换的理由。
> 但我可以帮您做几件事：
> 一是记录您的情况反馈给公司；
> 二是如果产品还有剩余且包装完好，我可以帮您申请，看是否符合其他退换条件；
> 三是如果您想换个方向，我可以帮您看看有没有更适合的方式。
> 具体能不能退，我需要提交给主管确认，不能当场答复您。

**3.**

> 首先把客户请到安静区域，避免影响其他客户；
> 然后倾听，不打断、不辩解；
> 明确告知"我没有权限当场处理，需要主管确认"；
> 立即请主管介入，并记录客户诉求原文。

**关键**：不能因为客户激动就承诺退款。

**4.**

**处理步骤**：

1. **先问身体状况**：「您现在感觉怎么样？有没有去医院？」
2. **建议就医**（如果明显不适）
3. **立即上报主管**，不走普通退换流程
4. 详细记录：吃了多少、多久、什么症状、何时开始
5. **保留剩余产品和包装**

**不能说的话**：

| ❌ | 为什么 |
|---|---|
| 「这个不会有什么问题的」 | 否认客户体验 |
| 「您是不是吃别的东西吃坏了」 | 质疑客户 + 推卸责任 |
| 「您先停了再看看」 | 隐含"是产品问题"的判断 |
| 「应该没事，观察一下」 | 你无权判断 |

**5.**

因为"无效退款"暗示了"应该有效"，构成**变相的效果承诺**。

保健食品不能宣称或暗示治疗效果，说"无效退款"等于承认产品应该有明确效果，这与"保健食品是辅助调节、不能承诺效果"的定位矛盾。

**可以说退款的情形**：
- 质量问题（商品责任）
- 7 天无理由（法定权利）

**不能说的情形**：
- 针对功效的"无效退款"

## 附录：处理流程图

```
客户提出退换
      │
      ├─ 涉及身体不适？
      │      └─ 是 → ①问身体状况 ②建议就医 ③立即上报 ④保留产品
      │                （不走普通流程）
      │
      └─ 否
          │
          ├─ 质量问题 / 描述不符 / 发错货？
          │      └─ 是 → 可退换，但仍需按规定登记
          │
          ├─ 未开封且 7 天内？
          │      └─ 是 → 按无理由退换政策
          │
          └─ 其他（含"没效果"）
                 └─ 记录诉求 → 说明政策 → 提交主管 → 按意见答复
                    （不承诺结果）
```

## 权限速查

| 事项 | 你的权限 |
|---|---|
| 受理退换诉求 | ✅ 可以 |
| 解释政策 | ✅ 可以 |
| 提交申请 | ✅ 可以 |
| 判断是否可退 | ❌ 不可以（主管判断） |
| 承诺退款金额 | ❌ 不可以 |
| 承诺到账时间 | ❌ 不可以 |
| 承认责任归属 | ❌ 不可以 |
