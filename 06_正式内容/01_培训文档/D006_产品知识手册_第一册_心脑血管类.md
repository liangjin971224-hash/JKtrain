## 本品类客户画像

| 特征 | 说明 |
|---|---|
| 年龄 | 通常在 45 岁以上 |
| 主要诉求 | 体检指标偏高、担心心血管问题、家里长辈有相关病史 |
| 常见认知误区 | 认为保健品可以替代药物、认为"吃了就能降下来" |
| **最需要强调的** | **不能代替药物，不能自己停药** |
| 最容易出事的地方 | 客户在服抗凝药，却不知道鱼油有出血风险 |

**这个品类是所有品类里风险最高的**，因为客户往往已经在服药，且对效果的期待很高。

## 产品一：康源牌鱼油软胶囊（P001）

### 一、基础信息

| 字段 | 内容 |
|---|---|
| 产品编号 | P001 |
| 产品名称 | 康源牌鱼油软胶囊 |
| **产品类别** | **保健食品** |
| **批准文号** | 国食健注G20250012 |
| 剂型 | 软胶囊 |
| 规格 | 1.0g/粒 × 60 粒/瓶 |
| 保质期 | 24 个月 |
| 贮存方法 | 密封，置阴凉干燥处 |
| 建议零售价 | 298 元 |

### 二、配料与成分

| 项 | 内容 |
|---|---|
| 配料表 | 鱼油、明胶、甘油、纯化水 |
| **标志性成分** | 每粒含鱼油 1000mg，其中 **EPA+DHA 合计 300mg** |
| 每日用量折算 | 按每日 4 粒计，摄入 EPA+DHA 约 1200mg |

### 三、批准功能与人群

| 字段 | 内容 |
|---|---|
| **批准保健功能** | **有助于维持血脂（胆固醇/甘油三酯）健康水平** |
| 适宜人群 | 血脂偏高者 |
| **不适宜人群** | 少年儿童；孕妇、乳母；**出血倾向者和出血性疾病患者**；肝功能不全者 |
| **注意事项** | **对海产品过敏者不推荐食用** |
| 食用方法 | 每日 2 次，每次 2 粒，随餐服用 |
| 每日用量上限 | 不超过 4.0g（其中 EPA+DHA 不低于 1.0g） |
| **强制警示语** | 保健食品不是药物，不能代替药物治疗疾病 |

### 四、高危禁忌场景（必须背）

| # | 客户说了什么 | 风险 | 你该怎么做 |
|---|---|---|---|
| **1** | **「我在吃阿司匹林 / 华法林 / 氯吡格雷」** | **出血风险** | **必须提示咨询医生，不能自己决定能不能吃** |
| **2** | 「我有出血性疾病 / 血小板低」 | 明确不适宜 | 建议不食用，说明原因 |
| **3** | 「我对海鲜过敏」 | 过敏风险 | 不推荐，说明注意事项 |
| **4** | 「我肝功能不太好」 | 明确不适宜 | 建议不食用 |
| **5** | 「我怀孕了 / 在哺乳」 | 明确不适宜 | 建议不食用 |
| **6** | 「我给孩子买」 | 明确不适宜 | 说明少年儿童不在适宜人群 |
| **7** | 「我还在吃其他保健品」 | 可能叠加 | 问清吃什么，建议咨询医生 |

**第 1 条是最关键的。** 出血风险是真实存在的临床问题，不是理论风险。

### 五、客户最常问的五个问题

**Q1：这个能降血脂吗？**

> ❌「能，很多人吃了血脂都降了」
> ✅「这款批准的功能是『有助于维持血脂（胆固醇/甘油三酯）健康水平』。需要说明的是，它是保健食品，不是药物，不能代替药物治疗疾病。如果您血脂偏高在用降脂药，用药一定要听医生的。」

**Q2：要吃多久？**

> 「保健食品是长期调理，不是药物，没有固定的见效时间，我也不能承诺效果。建议按说明规律食用，同时注意饮食和运动。」

**Q3：我在吃阿司匹林，能吃吗？**

> 「这款的不适宜人群包括出血倾向者和出血性疾病患者。阿司匹林有抗凝作用，两者同服可能增加出血风险。
> 这种情况建议您先咨询医生，让医生判断能不能吃、怎么吃。我这边不能给用药相关的建议。」

**Q4：你们这个和别家的鱼油有什么区别？**

> 「这个我不方便比较别家。我只能说我们这款的参数：每粒含鱼油 1000mg，其中 EPA+DHA 合计 300mg，规格是 60 粒装，批准文号是国食健注G20250012，您可以去市场监管总局官网核实。」

**Q5：为什么这么贵？**

> 「这款是 60 粒装，按每天 4 粒算可以吃 15 天，日均成本大约 20 元。
> 如果您觉得预算有压力，可以先从饮食入手，比如每周吃两次深海鱼，这也是 EPA 和 DHA 的来源。
> 或者我们还有规格小一点的，我可以帮您看看。」

**注意 Q5 的处理**：给了两个替代路径，其中一个是**不买**。

### 六、不能说的话（针对本产品）

| ❌ 不能说 | 原因 |
|---|---|
| 降血脂 / 降胆固醇 / 清血管 | 医疗术语 |
| 预防心脑血管疾病 | 疾病预防宣称 |
| 可以替代他汀类药物 | 替代药物宣称 |
| 吃了就不用吃降脂药了 | **最严重** |
| 深海鱼油比普通鱼油好 | 贬低其他产品（且属无依据比较） |
| 老人小孩都能吃 | 少年儿童是明确不适宜人群 |

## 产品二：康源牌辅酶Q10软胶囊（P002）

### 一、基础信息

| 字段 | 内容 |
|---|---|
| 产品编号 | P002 |
| 产品名称 | 康源牌辅酶Q10软胶囊 |
| **产品类别** | **保健食品** |
| **批准文号** | 国食健注G20250013 |
| 剂型 | 软胶囊 |
| 规格 | 0.3g/粒 × 60 粒/瓶 |
| 保质期 | 24 个月 |
| 建议零售价 | 368 元 |

### 二、配料与成分

| 项 | 内容 |
|---|---|
| 配料表 | 辅酶Q10、大豆油、明胶、甘油、纯化水 |
| **标志性成分** | 每粒含辅酶Q10 40mg |

### 三、批准功能与人群

| 字段 | 内容 |
|---|---|
| **批准保健功能** | **有助于增强免疫力；有助于抗氧化** |
| 适宜人群 | 成人 |
| **不适宜人群** | 少年儿童、孕妇、乳母、**过敏体质人群** |
| **注意事项** | **服用治疗药物的人群食用本品时应向医生咨询** |
| 食用方法 | 每日 1 次，每次 1 粒，餐后服用 |
| 每日用量上限 | 30–50mg |
| **强制警示语** | 保健食品不是药物，不能代替药物治疗疾病 |

### 四、高危禁忌场景

| # | 客户说了什么 | 风险 | 你该怎么做 |
|---|---|---|---|
| **1** | **「我在吃他汀类降脂药」** | 需医生评估 | **提示咨询医生** |
| **2** | 「我在吃降压药 / 降糖药」 | 需医生评估 | 提示咨询医生 |
| **3** | 「我是过敏体质」 | 明确不适宜 | 建议不食用 |
| **4** | 「我怀孕了 / 在哺乳」 | 明确不适宜 | 建议不食用 |
| **5** | 「给孩子吃」 | 明确不适宜 | 说明只适宜成人 |

**为什么他汀类要特别提示**：辅酶Q10 与胆固醇合成通路相关，服用他汀类药物的人群常关注辅酶Q10，但是否需要补充、补多少，应由医生判断。

### 五、客户最常问的四个问题

**Q1：这个对心脏好不好？**

> 「这款批准的功能是『有助于增强免疫力』和『有助于抗氧化』，**没有批准与心脏相关的功能声称**，所以我不能说它对心脏有什么作用。
> 如果客户本身有心脏方面的疾病，一定要以医生的治疗方案为准。」

**这个回答很重要**：客户以为辅酶Q10是"护心"的，但批件里没有这个功能。必须明确说没有。

**Q2：吃他汀是不是要吃这个？**

> 「这个需要医生判断。辅酶Q10 是我们身体自己也会合成的物质，但要不要额外补充、补多少，得看您的情况，我这边不能给建议。
> 您可以在复诊的时候问一下医生。」

**Q3：什么时候吃比较好？**

> 「建议餐后服用，每日 1 次，每次 1 粒。脂溶性成分随餐吃吸收会好一些。」

**Q4：这个能长期吃吗？**

> 「按说明书用量可以长期食用。但要提醒您，每日用量不要超过 50mg。
> 另外如果您在服用治疗药物，建议定期跟医生沟通。」

### 六、不能说的话（针对本产品）

| ❌ 不能说 | 原因 |
|---|---|
| 护心 / 保护心脏 / 强心 | 超出批准功能 |
| 预防心脏病 | 疾病预防宣称 |
| 吃他汀必须配这个 | 医疗建议 |
| 抗衰老 | 目录内是"有助于抗氧化"，不是"抗衰老" |
| 提高精力、改善疲劳 | 无此批准功能 |
| 可以和任何药一起吃 | 必须提示咨询医生 |

## 两款产品的对比速记

| 维度 | P001 鱼油 | P002 辅酶Q10 |
|---|---|---|
| 批准功能 | 有助于维持血脂健康水平 | 有助于增强免疫力；有助于抗氧化 |
| 适宜人群 | 血脂偏高者 | 成人 |
| **最高危禁忌** | **出血倾向 / 抗凝药** | 需医生评估（服药人群） |
| 不适宜人群数量 | 4 类 | 4 类（含过敏体质） |
| 每日上限 | ≤ 4.0g | 30–50mg |
| 剂型规格 | 1.0g × 60 | 0.3g × 60 |
| 常见误区 | 以为能降血脂 | **以为能护心** |

### 一句话区分

> **鱼油管"血脂"，辅酶Q10 管"抗氧化与免疫"。**
> 两个都**不管心脏**——这一点必须说清，因为客户最容易误会。

## 推荐前必须确认的三件事

在推荐这两款产品之前，必须问清：

| # | 必须确认 | 为什么 |
|---|---|---|
| **1** | **是否在服药**（特别是抗凝药、降脂药、降压药） | 直接关系安全 |
| **2** | **有无过敏史**（海鲜、其他） | 鱼油涉及海产品 |
| **3** | 是否在孕期/哺乳期、是否给儿童用 | 明确不适宜人群 |

**这三条问不清，就不要往下推荐。** 宁可少做一单，也不能出事。

### 参考答案

**1.**

有助于维持血脂（胆固醇/甘油三酯）健康水平。

**2.**

> 这款的不适宜人群包括出血倾向者和出血性疾病患者。华法林是抗凝药，两者同服可能增加出血风险。
> 这种情况建议您先咨询医生，让医生判断能不能吃。
> 我这边不能给用药相关的建议。

要点：说明禁忌 + 建议医生 + 明确不给用药建议。

**3.**

**没有。** 批准功能只有「有助于增强免疫力」和「有助于抗氧化」。

正确回答：
> 这款批准的功能是「有助于增强免疫力」和「有助于抗氧化」，没有批准与心脏相关的功能声称，所以我不能说它对心脏有什么作用。
> 如果您有心脏方面的疾病，一定要以医生的治疗方案为准。

**4. A、B、C、D**

E 不在不适宜人群中——鱼油的适宜人群本身就是"血脂偏高者"，高血压不是禁忌。

**5.**

> 这款产品的适宜人群是血脂偏高的成人，少年儿童属于不适宜人群，所以不建议给孩子吃。
> 如果孩子有健康方面的需要，建议先咨询儿科医生或者营养专业人员。
> 孩子的营养主要还是要靠日常饮食。

要点：明确不适宜 + 给替代路径（咨询儿科医生）+ 不空手（饮食建议）。

**6.**

**P002 辅酶Q10 最容易误解**，误解是「能保护心脏」。

原因：市场上很多辅酶Q10 的宣传都围绕"护心"，客户会带着这个认知来问。但公司这款产品的批准功能里**没有与心脏相关的声称**，必须明确说明。
