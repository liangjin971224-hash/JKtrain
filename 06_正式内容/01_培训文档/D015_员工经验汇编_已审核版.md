## 关于本文档（必读）

### 为什么经验必须改写

老员工的经验里，天然夹杂一些**在当时有效但实际违规**的做法：

| 原始经验 | 问题 |
|---|---|
| 「你就跟他说能降血糖，成交率高」 | **违规宣称** |
| 「客户犹豫就说现在有活动，先带两盒」 | **主动推销** |
| 「问他效果就说很多人都说好」 | **他人经验背书** |
| 「老年人特别认这个，一说就买」 | **人群功效暗示** |

**如果这些直接入库，系统会亲手把违规话术教给新人。**

所以每一条经验都必须经过：

```
原始经验
   ↓
① 合规扫描（禁用词 + 功效边界）
   ↓
② 改写（保留情境 + 处理思路，删除具体话术）
   ↓
③ 领域审核（业务 + 合规双审）
   ↓
④ 入库（标注为"经验参考"，非公司规范）
```

### 改写四原则

| # | 原则 | 说明 |
|---|---|---|
| **1** | 保留**情境**（客户什么情况） | 这是经验的真正价值 |
| **2** | 保留**处理思路**（为什么这么做） | 这是可迁移的方法 |
| **3** | **删除具体话术表述** | 避免被当模板照搬 |
| **4** | **删除任何功效宣称与推销动作** | 合规底线 |

## 第一章 需求识别类经验

### 经验 E001：客户说"我就随便看看"

| 项 | 内容 |
|---|---|
| **情境** | 客户进店后说"随便看看"，不主动说需求 |
| **常见错误** | 追着介绍产品，客户很快离开 |
| **处理思路** | 保持距离，先给空间。可以说"您先看看，有需要随时叫我"，然后做自己的事但保持留意。客户通常会在一段时间后主动提问，或者在某一产品前停留较久——这时再过去 |
| **为什么有效** | "随便看看"往往是有需求但还在观察。追着讲会让客户有压力；给空间反而降低防备 |
| **教学点** | 不打扰也是一种服务 |

### 经验 E002：客户带着家人一起来

| 项 | 内容 |
|---|---|
| **情境** | 客户由子女或配偶陪同到店 |
| **常见错误** | 只跟主客户说话，忽略同行人 |
| **处理思路** | ①先照顾同行人（让座、递水）②了解关系（是谁在关心谁的健康）③说明时**同时照顾两个人的理解**④如果同行人是决策影响者，要让他也听懂 |
| **为什么有效** | 家人的态度往往决定最终是否购买。而且同行人往往是真正关心客户健康的人 |
| **教学点** | 服务的是一个家庭，不只是一个人 |

### 经验 E003：客户一上来就问价格

| 项 | 内容 |
|---|---|
| **情境** | 客户还没了解产品就先问"多少钱" |
| **常见错误** | 直接报价格，然后客户说"太贵了"就走了 |
| **处理思路** | 先报价格但**立即补充规格和用量**——把总价换算成日均成本，同时说明"可以先了解一下是不是您需要的，价格我们再谈" |
| **为什么有效** | 单看总价容易觉得贵，换算成日均成本后感知差别很大。而且先讲价值再谈价格，客户更容易接受 |
| **教学点** | 价格要放在价值之后讲，但不能回避价格 |

### 经验 E004：客户说"我什么都要补"

| 项 | 内容 |
|---|---|
| **情境** | 客户表达模糊的广泛需求，觉得哪哪都需要 |
| **常见错误** | 顺着客户推荐一堆产品 |
| **处理思路** | 用提问收窄："如果先从一个最想改善的开始，您会选哪个？"通常客户能说出一个最在意的点，从这里切入 |
| **为什么有效** | 一次解决一个问题，客户更容易看到效果，也更容易建立信任 |
| **教学点** | 需求越模糊，越要收窄，而不是扩大 |

## 第二章 产品说明类经验

### 经验 E005：客户问"这个和那个有什么区别"

| 项 | 内容 |
|---|---|
| **情境** | 客户在两款产品之间犹豫 |
| **常见错误** | 说"这个更好"或"那个效果强" |
| **处理思路** | 只陈述客观差异：成分、含量、规格、剂型、价格、适用人群。最后说"您按自己的情况和使用习惯选，我不做哪个更好的评价" |
| **为什么有效** | 做优劣评价既违规（绝对化/贬低），也会让客户怀疑你的动机。陈述事实让客户自己判断，反而更信任 |
| **教学点** | 帮客户做决定，而不是替客户做决定 |

### 经验 E006：客户问"要吃多久"

| 项 | 内容 |
|---|---|
| **情境** | 客户想知道多久见效 |
| **常见错误** | 说"一个月"、"三个疗程"或"因人而异"（后者太敷衍） |
| **处理思路** | 说明两点：①保健食品是长期调理，不是药物，没有固定见效时间 ②不能承诺效果，但建议按说明规律食用，同时配合饮食和作息 |
| **为什么有效** | 给时间承诺是违规的；"因人而异"又显得敷衍。把重点转到"规律食用 + 生活方式配合"，既诚实又给出了可执行的动作 |
| **教学点** | 不能给时间，但可以给方法 |

### 经验 E007：客户问"能不能长期吃"

| 项 | 内容 |
|---|---|
| **情境** | 客户担心长期食用的安全性 |
| **常见错误** | 说"纯天然的，随便吃"或"长期吃没问题" |
| **处理思路** | 说明：①按说明书用量可以长期食用 ②有每日用量上限，不要超量 ③如果在服药，建议定期跟医生沟通 ④饮食已经能满足的情况下，不建议长期依赖补充剂 |
| **为什么有效** | 既回答了问题，又强调了用量限制，还给了"不依赖"的建议——这种回答会让客户觉得你是真的在为他想 |
| **教学点** | 说"可以长期吃"的同时，必须说清用量限制 |

### 经验 E008：客户拿着别的品牌来问

| 项 | 内容 |
|---|---|
| **情境** | 客户拿着竞品或网上买的产品来问"这个好不好" |
| **常见错误** | 说"这个不行"、"成分不好"、"别买了" |
| **处理思路** | ①不评价别家产品 ②可以帮客户看他手里的产品**是什么类别**（有没有蓝帽子）③教他怎么核实批准文号 ④说明"您自己判断，我只帮您看这个信息" |
| **为什么有效** | 贬低竞品违规且显得不专业。而教客户自己核实，反而体现了专业性，也建立了信任 |
| **教学点** | 教方法比给结论更有价值 |

## 第三章 异议处理类经验

### 经验 E009：客户说"太贵了"

| 项 | 内容 |
|---|---|
| **情境** | 客户对价格有顾虑 |
| **常见错误** | 说"别家更贵"或"现在有活动赶紧买" |
| **处理思路** | ①换算日均成本 ②提供更小规格的选择 ③说明也可以通过饮食解决（不买也是选项）④给客户时间考虑 |
| **为什么有效** | 提供"不买"的选项，反而让客户觉得你不是只想卖东西。很多客户会因为这份坦诚而回头 |
| **教学点** | 敢说不买，才能赢得长期信任 |

### 经验 E010：客户说"我朋友吃了没用"

| 项 | 内容 |
|---|---|
| **情境** | 客户用他人经验质疑 |
| **常见错误** | 说"他吃的方法不对"或"我们这款不一样" |
| **处理思路** | ①先认同失望的情绪 ②说明个体差异 ③不承诺效果 ④转向了解客户自己的情况 ⑤**不否定朋友的体验** |
| **为什么有效** | 否定朋友的体验等于否定客户的判断，会引发对抗。认同情绪 + 转向了解，能把对话拉回建设性方向 |
| **教学点** | 认同情绪，不认同结论 |

### 经验 E011：客户说"你们是不是骗人的"

| 项 | 内容 |
|---|---|
| **情境** | 客户对公司和产品有根本性怀疑 |
| **常见错误** | 辩解"我们开了十几年"或情绪化回应 |
| **处理思路** | ①认同警惕（"您有这个警惕是对的"）②给可核实的方法（批准文号 + 官网查询路径）③敢让客户去查 |
| **为什么有效** | 怀疑的客户要的不是保证，是**可验证的证据**。敢让他去查，比任何承诺都有说服力 |
| **教学点** | 给方法，不给保证 |

### 经验 E012：客户坚持要停药

| 项 | 内容 |
|---|---|
| **情境** | 客户相信保健品可以替代药物，想停药 |
| **常见错误** | 妥协说"可以试试""慢慢减" |
| **处理思路** | **一步不让**：①明确说"不可以" ②说明保健食品不能代替药物 ③用药调整必须由医生决定 ④对他人经验做正确回应（个体差异）⑤引导到自己能提供的帮助（饮食、生活方式） |
| **为什么有效** | 这是唯一"零容忍"的类型。妥协的代价是客户的身体。守住底线即使丢单，也是对的 |
| **教学点** | 有些话，丢单也要说 |

### 经验 E013：客户说"我不想吃保健品，我想靠饮食"

| 项 | 内容 |
|---|---|
| **情境** | 客户明确表示倾向通过饮食改善 |
| **常见错误** | 说"但饮食不够啊"、"现代人饮食都不均衡" |
| **处理思路** | **认同并支持**："您这个想法很对，大多数营养需求都可以通过饮食满足"。然后提供价值：帮他看饮食结构，给具体调整建议 |
| **为什么有效** | 这个客户是对的。顺着他的方向提供专业价值，反而能建立最强的信任——因为他会发现你是真的在帮他，而不是在卖东西 |
| **教学点** | 客户对的时候，要明确说他对 |

## 第四章 服务细节类经验

### 经验 E014：客户犹豫不决时

| 项 | 内容 |
|---|---|
| **情境** | 客户了解完产品，但迟迟不决定 |
| **常见错误** | 施压（"今天最后一天""这批快没了"） |
| **处理思路** | ①给可带走的信息（把关键点写下来）②说"不用急着决定，想好了随时来" ③留联系方式 ④说明可以后续咨询 |
| **为什么有效** | 健康消费应该是理性的。施压会导致冲动购买后后悔、退货、投诉。给空间反而提高成交质量和复购率 |
| **教学点** | 不施压，是长期生意的基础 |

### 经验 E015：客户买了之后怎么跟进

| 项 | 内容 |
|---|---|
| **情境** | 客户已购买，需要售后跟进 |
| **常见错误** | 直接问"要不要再买一盒" |
| **处理思路** | 按时间节点跟进：①3 天内问"用着还顺利吗，有没有什么问题" ②1 周后问"有没有坚持，遇到什么困难" ③1 个月后做效果回顾 ④每次跟进**先关心，后推荐** |
| **为什么有效** | 跟进的第一句话决定客户感受。先关心使用体验，客户会觉得你在服务；直接推销，客户会觉得你只关心业绩 |
| **教学点** | 跟进是服务，不是催单 |

### 经验 E016：客户问了一个你答不上来的问题

| 项 | 内容 |
|---|---|
| **情境** | 客户问了超出你知识范围的问题 |
| **常见错误** | ①编一个答案 ②说"这个我不清楚"就结束 |
| **处理思路** | ①诚实说"这个我需要查一下产品资料/问一下同事" ②**当场去查或问**，不要拖 ③查到后主动回复客户 |
| **为什么有效** | 编答案的风险极高（可能违规、可能错误）。而"我查一下马上告诉您"体现的是认真，不是无能 |
| **教学点** | 承认不知道不可怕，编答案才可怕 |

### 经验 E017：客户在店里提到身体不适

| 项 | 内容 |
|---|---|
| **情境** | 客户随口提到"最近总头晕""胃不太舒服" |
| **常见错误** | 顺着分析"您这个可能是 XX 引起的" |
| **处理思路** | ①关心但不分析（"那您有没有去看过？"）②如果客户说没看，建议就医 ③如果客户已经在治疗，问"医生怎么说" ④**不做任何病因推测** |
| **为什么有效** | 分析病因就是诊断，属越界。而且你的推测可能误导客户 |
| **教学点** | 关心可以，分析不行 |

## 第五章 学习成长类经验

### 经验 E018：怎么快速记住产品参数

| 项 | 内容 |
|---|---|
| **方法** | ①先记"三件套"：类别（保健食品/普通食品）、批准功能原文、不适宜人群 ②再记参数（成分、规格、用量）③用对比法记（同类产品放一起比对差异）④每天挑一个产品，脱稿讲一遍 |
| **为什么有效** | 参数记错可以查，但类别和功能声称说错就是违规。先记高风险的，再记低风险的 |
| **教学点** | 先记"不能错的"，再记"能查的" |

### 经验 E019：遇到不懂的客户问题怎么积累

| 项 | 内容 |
|---|---|
| **方法** | ①当天记下来（问题原文 + 当时的回答）②查资料或问同事 ③记录正确答案 ④每周回顾一次 |
| **为什么有效** | 客户的问题是最好的教材。三个月积累下来的问题清单，比任何培训资料都实用 |
| **教学点** | 把不会的问题变成会的问题 |

### 经验 E020：怎么判断自己是否越界了

| 项 | 内容 |
|---|---|
| **自检三问** | ①这句话里有没有"降、治、最、保证"这类词？②如果客户录音后拿去投诉，我这句话站得住吗？③这句话如果被贴在门店墙上，我敢不敢？ |
| **为什么有效** | 第三个问题最有效——很多违规话术是"私下说说"，一旦想到会被公开，就会自己收住 |
| **教学点** | 不能公开说的话，就是不该说的话 |

## 第六章 使用说明

### 6.1 这些经验的定位

| 是 | 不是 |
|---|---|
| **参考思路** | 标准话术 |
| 告诉你在某种情境下可以怎么想 | 让你照搬某句话 |
| 经审核的、合规的做法 | 未经审核的个人经验 |

**使用时必须注意**：本文档的所有内容都是"思路参考"，不是"话术模板"。实际沟通时用自己的话表达，但**必须遵守 D005 的合规要求**。

### 6.2 如果发现经验里有问题

如果你在实际使用中发现某条经验：
- 不适用当前情况
- 可能导致违规
- 有更好的做法

**请立即反馈给主管**，不要自行修改，也不要继续使用。

### 6.3 新经验的提交

如果你有一条好经验想贡献：

| 步骤 | 说明 |
|---|---|
| 1 | 写成"情境 + 处理思路 + 为什么有效"三段 |
| 2 | 提交给主管 |
| 3 | 经业务 + 合规双审 |
| 4 | 审核通过后入库 |

**注意**：**不要直接写"我当时是这么说的"**——那会带入具体话术，审核时会被退回改写。

## 自测题

**1. 为什么员工经验必须经过改写才能入库？举一个原始经验的例子说明。**

**2. 客户说"我朋友吃了没效果"，以下哪个回应是错的？**
A. 认同失望的情绪
B. 说明个体差异
C. 说"他吃的方法不对"
D. 转向了解客户自己的情况

**3. 客户坚持要停药，你应该怎么做？**

**4. 客户说"我不想吃保健品，想靠饮食"，这个异议应该怎么处理？**

**5. 客户问了一个你答不上来的问题，正确的做法是什么？**

**6. 「不能公开说的话，就是不该说的话」——这句话为什么有效？**

---

### 参考答案

**1.**

因为老员工的经验里天然夹杂违规做法。

**例子**：

```
原始经验：「客户问能不能降血糖，就说能降，成交率很高」
      ↑ 这是违规宣称（降血糖是医疗术语）

改写后：「客户询问功效时，先说明产品属保健食品、不能替代药物，
        再引导到饮食管理方案，客户接受度较好」
      ↑ 保留了情境和处理思路，删掉了违规表述
```

如果不改写，系统会把违规话术教给新人。

**2. C**

「他吃的方法不对」是在否定客户的判断（因为客户是相信他朋友的），会引发对抗。

正确做法是认同情绪、说明个体差异、转向了解客户自己的情况，**但不否定朋友的体验**。

**3.**

**一步不让，明确说不可以。**

> 不可以。保健食品不能代替药物，更不能替代您的降压药。
> 用药调整必须由医生根据您的情况决定，我这边不能给任何用药建议。
> 您朋友的情况我不了解，每个人的情况不一样，不建议照搬。
> 我能帮您的是饮食和生活方式上的建议，但药一定不能自己停。

**关键**：任何"试试""减半""看情况"都不能说。即使因此丢单，也必须守住。

**4.**

**认同并支持客户的选择。**

> 您这个想法很对。其实大多数营养需求都可以通过饮食满足，保健食品只是补充手段，不是必需的。
> 如果您愿意，我可以帮您看看现在的饮食结构，看有没有需要调整的地方。

**为什么**：这个客户是对的。顺着他的方向提供专业价值，反而能建立最强的信任。

**5.**

> ①诚实说"这个我需要查一下产品资料，或者问一下同事"
> ②**当场去查或问**，不要拖到"我回头告诉您"
> ③查到后主动回复客户

**绝不能做的事**：编一个答案。编答案的风险极高（可能违规、可能错误），而"我查一下马上告诉您"体现的是认真。

**6.**

因为很多违规话术是"私下说说"的。

一旦你想到"这句话如果被贴在门店墙上，我敢不敢"——答案往往是不敢。那它就属于不该说的话。

**这个自检的好处是**：它不依赖你记住具体的禁用词清单，而是用一个更根本的标准来判断——**能不能公开**。
