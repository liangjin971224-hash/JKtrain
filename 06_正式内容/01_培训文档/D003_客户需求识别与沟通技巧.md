## 学习目标

学完本文档，你应当能够：

1. 区分客户说的和客户真正需要的
2. 用四类提问把模糊需求问清
3. 识别四种信号，判断需求强度
4. 在客户表达不清时正确引导
5. 避免五种常见沟通错误

## 第一章 一个核心认知：说的 ≠ 要的

### 1.1 客户说的往往不是真正的需求

| 客户说的 | 表面需求 | 可能真正的需求 |
|---|---|---|
| 「我想买点钙片」 | 买钙片 | 体检发现骨量减少，想防止继续下降 |
| 「有没有减肥的」 | 买减肥产品 | 想穿回以前的衣服 / 体检指标异常 / 被家人说胖 |
| 「我睡不好」 | 买助眠产品 | 工作压力大 / 作息乱 / 睡前刷手机 |
| 「我朋友吃这个挺好」 | 买同款 | 想找人帮他判断是否适合自己 |
| 「你们这个多少钱」 | 问价格 | 已经在考虑买，在确认预算是否合适 |
| 「我就随便看看」 | 无需求 | 有需求但还不信任，先来观察 |

### 1.2 为什么必须问清

**因为你基于表面需求给的建议，大概率是错的。**

一个典型例子：

```
客户："我想买点补钙的"
❌ 直接推荐钙片 → 客户买了 → 一周后回访说"没什么感觉"
✅ 先问："您平时喝奶或者吃豆制品多吗？"
   → 客户："我一天两杯奶"
   → 结论：钙摄入可能已足够，需要先搞清楚"想补钙"的来由
   → 继续问："是体检发现什么了吗？"
   → 客户："体检说骨密度偏低"
   → 这时才知道：真正需要的是先去医院评估，而不是自己买钙片
```

**问清之后，你的建议可能完全不同——甚至可能是"您先别买，先去医院"。**

这句话听起来像在放弃生意，实际上是**在建立信任**。而且这种做法会带来长期的复购和转介绍。

### 1.3 一个反直觉但重要的事实

> **你最有力的专业表现，往往是"告诉客户不需要买"。**

因为每个销售都在说"这个好"，只有你在说"你可能不需要"，客户会立刻把你和普通销售区分开。

## 第二章 四类提问

### 2.1 提问的四个层次

| 层次 | 目的 | 例子 | 什么时候用 |
|---|---|---|---|
| **1 开放式** | 让客户自由表达 | 「您今天主要想了解哪方面？」 | **开场必用** |
| **2 探究式** | 追问细节 | 「是体检发现的吗？大概多少？」 | 客户说了模糊信息时 |
| **3 澄清式** | 确认理解 | 「您的意思是希望先改善睡眠，还是先解决白天疲劳？」 | 客户表述矛盾时 |
| **4 引导式** | 把话题引到可解决的方向 | 「您刚才说作息不规律，如果从这个入手，您觉得可行吗？」 | 需求模糊但已有线索时 |

### 2.2 开放式提问（开场必用）

**为什么开场不能用封闭式**：

| 类型 | 例子 | 问题 |
|---|---|---|
| ❌ 封闭式 | 「您是来买保健品的吗？」 | 客户只能答是/不是，容易说「随便看看」就结束了 |
| ✅ 开放式 | 「您今天主要想了解哪方面？」 | 客户会主动说出关注点 |

**五个好用的开放式开场**：

1. 「您今天主要是想了解哪方面？」
2. 「是什么让您想到要来看看的？」
3. 「您平时在健康这块最关注什么？」
4. 「最近身体有没有什么让您不太舒服的？」（注意：问"不舒服"不是问病）
5. 「您之前有没有用过类似的产品？」（了解经验，判断认知水平）

### 2.3 探究式提问（追问细节）

**追问的三种角度**：

| 角度 | 例子 | 目的 |
|---|---|---|
| **时间** | 「这个情况大概多久了？」 | 判断是偶发还是长期 |
| **程度** | 「影响日常生活吗？比如……」 | 判断严重性（用生活场景，不问病情） |
| **已采取的行动** | 「有没有去医院看过？医生怎么说？」 | 了解是否在医疗管理下 |

**追问的边界（重要）**：

| 可以问 | 不可以问 |
|---|---|
| 什么时候发现的 | 具体检查数值是多少（如空腹血糖 7.8） |
| 医生有没有说什么 | 医生给你开的什么药、吃多少 |
| 现在在吃药吗（**问是否，不问药名和剂量**） | 你这个病几年了、到什么程度了 |

**为什么有这个边界**：追问病情细节等于在问诊。你只需知道"是否在医疗管理下"，不需要知道具体诊断和治疗方案。

### 2.4 澄清式提问（消除歧义）

当客户表述模糊或矛盾时用：

| 客户说 | 澄清问法 |
|---|---|
| 「我想调理一下」 | 「您说的调理，主要是想改善哪方面？睡眠、精神、还是消化？」 |
| 「我身体不太好」 | 「方便说是哪方面让您觉得不太好？是容易累，还是睡不好？」 |
| 「我什么都要补」 | 「如果先从一个最想改善的开始，您会选哪个？」 |
| 「我朋友说这个好，我也想买」 | 「您朋友当时是什么情况？您现在的情况和他类似吗？」 |

### 2.5 引导式提问（把话题引向可解决方向）

**注意：引导不等于诱导。**

| | 引导（正确） | 诱导（错误） |
|---|---|---|
| 目的 | 帮客户聚焦到可执行的方向 | 把客户引向你准备好的产品 |
| 例子 | 「您刚才说作息不规律，如果先从调整作息入手，您觉得可行吗？」 | 「您这个情况啊，正好我们这款产品就是针对这个的」 |
| 客户感受 | 被帮助 | 被推销 |

## 第三章 判断需求强度的四个信号

问完之后，你要判断：这个客户现在到底有多需要、多急。

### 3.1 四个信号

| 信号 | 强需求表现 | 弱需求表现 |
|---|---|---|
| **1 主动性** | 主动问细节、主动说自己的情况 | 只答不问，被动回应 |
| **2 具体性** | 能说出时间、场景、影响 | 说得笼统（"就是不太舒服"） |
| **3 已行动** | 已经去过医院、查过资料、试过方法 | 完全没采取过任何行动 |
| **4 紧迫感** | 有明确时间点（"下个月要体检"） | 没有时间概念（"有空再说"） |

### 3.2 四象限判断

```
        主动性高
            │
   观望型   │   明确型
  （需培育）│ （可推进）
────────────┼──────────── 具体性高
   无感型   │   焦虑型
  （不打扰）│ （需安抚）
            │
        主动性低
```

| 类型 | 特征 | 应对 |
|---|---|---|
| **明确型** | 主动 + 具体 | 直接给方案，不绕弯 |
| **焦虑型** | 具体但被动（很担心，但不知怎么办） | **先安抚情绪，再给信息**，不要一上来就讲产品 |
| **观望型** | 主动但笼统（在了解阶段） | 给知识、给资料，**不催成交**，留联系方式 |
| **无感型** | 被动 + 笼统 | 不打扰，简单介绍后让客户自己看 |

**最容易做错的是「焦虑型」**：这类客户担心得很多，你越讲产品他越焦虑。正确做法是先让他安心（"这个情况很常见""您先别急"），再给具体信息。

### 3.3 一个判断口诀

> **主动问细节的，是想解决问题；只答不问的，是在考察你。**

## 第四章 五种常见沟通错误

### 4.1 错误一：急于给方案

| | 表现 |
|---|---|
| ❌ | 客户刚说完"我睡不好"，你就开始介绍助眠产品 |
| 为什么错 | 你还不知道他为什么睡不好，方案必然不准 |
| ✅ | 先问：「是睡不着，还是容易醒？大概多久了？」 |

### 4.2 错误二：过度共情变成附和

| | 表现 |
|---|---|
| ❌ | 客户说"西药伤肾"，你说"是啊，西药确实伤身" |
| 为什么错 | **这是附和错误认知**，而且贬低了药品 |
| ✅ | 「您这个担心我理解。不过降压药是医生根据您的情况开的，要不要调整得听医生的。」 |

**共情感受，但不认同错误认知** —— 这是最难把握的一条。

### 4.3 错误三：用专业术语制造距离

| | 表现 |
|---|---|
| ❌ | 「您的 BMI 偏高，建议控制 GI 摄入，增加膳食纤维」 |
| 为什么错 | 客户听不懂，会觉得你在显摆 |
| ✅ | 「您的体重相对身高来说偏高一些，建议少吃点精米白面，多吃点粗粮和蔬菜」 |

**专业不是用术语，是让对方听懂。**

### 4.4 错误四：被客户带着走

| | 表现 |
|---|---|
| ❌ | 客户问"这个能治糖尿病吗"，你就顺着讨论能不能治 |
| 为什么错 | 一旦进入这个讨论，你就已经越界了 |
| ✅ | 「这个不是药，不能治病。它批准的功能是『……』。您糖尿病的情况得听医生的。」 |

**要主动把话题拉回边界内**，而不是被动应答。

### 4.5 错误五：回避（看起来谨慎，实际失职）

| | 表现 |
|---|---|
| ❌ | 客户问"你们有鱼油吗"，你说"这个我不太清楚" / "您问医生吧" |
| 为什么错 | 产品信息不是医学判断，回避就是失职 |
| ✅ | 「有的，XX 鱼油软胶囊，每粒含……这是保健食品，批准的功能是……」 |

**界线**：
- **说明书上有的**（成分、规格、用法、不适宜人群）→ **必须答**
- **说明书上没有的**（疾病判断、用药建议）→ 可以说需要医生

## 第五章 三个完整沟通示例

### 示例一：客户说「我想补钙」

**❌ 错误示范**：

> 顾客：我想补点钙。
> 顾问：我们这个钙片挺好的，一天一片，很多人都买。

问题：没问需求、直接推荐、以他人经验背书。

**✅ 正确示范**：

> 顾客：我想补点钙。
>
> 顾问：好的。方便问一下，您是体检发现什么了，还是平时觉得需要补？
>
> 顾客：体检查出来骨密度偏低。
>
> 顾问：明白了。这个情况我建议您先带报告去医院看一下，让医生判断需不需要干预，以及怎么干预。
>
> 顾客：那我不需要补钙吗？
>
> 顾问：不是说不需要，而是先要搞清楚程度。日常饮食上，如果您平时喝奶不多，可以先从增加奶制品、豆制品入手，这是钙的主要来源。
>
> 顾问：您平时一天大概喝多少奶？
>
> 顾客：基本不喝，我不太喜欢。
>
> 顾问：那确实可能钙摄入不太够。除了奶，豆腐、豆干、深绿色蔬菜、芝麻酱也有钙。您可以先从饮食调整试试。
>
> 顾问：如果确实饮食上很难做到，我们再谈要不要用补充剂。而且您这个情况，最好还是先听医生的意见。
>
> 顾客：行，我先去医院看看。

**这个示范的关键动作**：
1. 先问来由（不直接推荐）
2. 涉及体检指标 → **建议先就医**
3. 优先饮食方案
4. 用提问了解实际摄入情况
5. 把"要不要买"的决定权交回客户

**注意最后结果**：客户当天没买任何东西。但这个客户的信任建立了，而且他去医院后会回来——因为他知道这里的人是靠谱的。

### 示例二：客户说「我睡不好」

**✅ 正确示范**：

> 顾客：我最近睡不好。
>
> 顾问：是睡不着，还是睡着了容易醒？
>
> 顾客：躺下翻来覆去睡不着，得刷手机刷到很晚才困。
>
> 顾问：大概多久了？
>
> 顾客：得有两三个月了，工作压力大。
>
> 顾问：那确实挺熬人的。睡前刷手机这个习惯，其实会让大脑更清醒，因为屏幕的光会影响褪黑素分泌。
>
> 顾问：您平时几点上床？大概刷多久？
>
> 顾客：十一二点上床，得刷一个多小时。
>
> 顾问：如果试着把手机放远一点，或者提前半小时放下，可能会好一些。这个不用花钱，可以先试一周看看。
>
> 顾客：那你们有没有助眠的产品？
>
> 顾问：有的，我们有一款褪黑素片。不过这个我要先说明几点：
> 一是它是保健食品，不是药物，不能代替药物治疗疾病，批准的功能是「有助于改善睡眠」；
> 二是不适宜人群包括少年儿童、孕妇、乳母；
> 三是如果您要开车或者做危险操作，不能在操作前或操作中吃；
> 四是自身免疫性疾病和甲亢的患者要慎用。
>
> 顾问：您的情况我建议先把作息调一调。如果一两周还是不行，再考虑用产品，或者去看看医生。
>
> 顾客：好，我先试试调作息。

**这个示范的关键动作**：
1. 用提问区分类型（睡不着 vs 易醒）
2. 找到可能的**生活方式原因**（睡前刷手机）
3. **先给免费方案**（调整作息）
4. 客户主动问产品时**如实回答，且说全五要素**
5. 建议先试非产品方案

### 示例三：客户说「我朋友吃这个挺好，我也想买」

**✅ 正确示范**：

> 顾客：我朋友吃你们那个蛋白粉挺好的，我也想买。
>
> 顾问：您朋友是什么情况用的？
>
> 顾客：他健身，说要增肌。
>
> 顾问：明白了。那您想用主要是想达到什么效果？
>
> 顾客：我就是觉得自己体力差，容易累。
>
> 顾问：这两件事其实不太一样。健身增肌需要额外的蛋白质补充，而容易累的原因可能有很多，不一定是蛋白不足。
>
> 顾问：您平时三餐吃得怎么样？肉、蛋、奶吃得多吗？
>
> 顾客：早上一般不吃，中午随便吃，晚上正常。
>
> 顾问：那问题可能不在蛋白质补充上，而是整体吃得太少了，特别是早餐。
>
> 顾问：另外我想问一下，您有没有在吃什么药？有没有什么食物过敏？
>
> 顾客：没吃药，不过我对牛奶有点不太舒服。
>
> 顾问：那乳清蛋白可能不太适合，会涉及到乳制品。我们还有一款大豆分离蛋白，是植物蛋白。
>
> 顾问：不过我还是建议您先把三餐规律起来，特别是早餐。如果一两周后还是觉得累，我们再具体看。
>
> 顾客：那我先试试吃早饭。

**这个示范的关键动作**：
1. **问清朋友的情况**（避免盲目复制他人方案）
2. **澄清真实需求**（增肌 vs 体力差，是两回事）
3. **找到真正的问题**（三餐不规律）
4. **问过敏和用药**（安全底线）
5. 根据过敏情况**调整推荐方向**（乳清 → 大豆）
6. 仍建议先试生活方式

## 第六章 自测题

**1. 客户说「我想买点补钙的」，你的第一步应该做什么？**

**2. 以下哪个开场提问更好？为什么？**
A. 「您是来买保健品的吗？」
B. 「您今天主要想了解哪方面？」

**3. 客户说「西药伤肾，我不敢长期吃」，你该怎么回应？**

**4. 追问病情时，以下哪些可以问？（多选）**
A. 这个情况大概多久了
B. 您的空腹血糖具体是多少
C. 有没有去医院看过
D. 医生给你开的什么药、吃多少
E. 现在有没有在吃药

**5. 客户很焦虑，一直问「我这个情况严重吗」，你应该先做什么？**

**6. 判断以下说法对错：客户说「我就随便看看」，说明没有需求，不用理他。**

### 参考答案

**1.**

先问来由，不要直接推荐：

> 「方便问一下，您是体检发现什么了，还是平时觉得需要补？」

如果客户说是体检发现骨密度偏低，**应建议先带报告就医**，而不是直接推荐钙片。

**2. B**

A 是封闭式提问，客户只能答"是"或"不是"，容易直接结束对话。
B 是开放式提问，客户会主动说出关注点，你才能判断方向。

**3.**

> 您这个担心我理解。不过降压药是医生根据您的血压情况开的，要不要调整、能不能减量，需要医生来判断。
> 我这边不能给用药建议，如果您担心副作用，可以把这个顾虑跟医生说一下。

要点：**共情感受，但不附和错误认知**，也不能贬低药品。

**4. A、C、E**

B、D 属于追问病情细节和治疗方案，越界。
A（时间）、C（是否就医）、E（是否在服药）是判断"是否在医疗管理下"的必要信息，属于合理范围。

**5.**

**先安抚，再给信息。**

> 「这个情况其实挺常见的，您先别太着急。」

焦虑型客户越讲产品越焦虑，必须先让他安心，再逐步给具体建议。

**6. 错误**

「随便看看」往往意味着**有需求但还不信任**，正在观察你。

正确做法：不追着介绍，说「您先看看，有需要随时叫我」，保持适当距离，但不要冷落。
