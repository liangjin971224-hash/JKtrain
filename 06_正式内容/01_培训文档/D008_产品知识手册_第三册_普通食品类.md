## 为什么单独一册讲普通食品

因为这五个产品和前两册的保健食品**外观相似、成分相似，但类别完全不同**。

| | 保健食品 | 普通食品 |
|---|---|---|
| 批准标识 | 蓝帽子 + 食健备/国食健注 | SC 编号 |
| 能否说功能 | 能（限目录 24 项） | **一个字都不能说** |
| 典型错误 | 说了目录外的功能 | **说了任何功能** |

**这一册的核心只有一句话**：

> **普通食品，不能宣称任何保健功能。连"有助于"都不能说。**

## 第一章 普通食品的三条铁律

### 1.1 三条铁律

| # | 铁律 | 违反后果 |
|---|---|---|
| **1** | **不能作任何保健功能声称** | 违反《食品安全法》，属虚假宣传 |
| **2** | **不能暗示疾病预防、治疗功能** | 违反《广告法》 |
| **3** | **不能使用与已批准保健食品相同的名称** | 违反市场监管总局规定 |

### 1.2 什么是"任何功能声称"

**这个范围比你想的宽得多。**

| ❌ 不能说 | 为什么 |
|---|---|
| 增强免疫力 / 有助于增强免疫力 | 保健功能声称 |
| 补充蛋白质效果好 | "效果好"属功能暗示 |
| 适合免疫力低的人 | 暗示调节免疫功能 |
| 改善皮肤弹性 | 保健功能声称 |
| 抗衰老 | 保健功能声称 |
| 养肝明目 / 补肾 | 中医功效声称 |
| 乌发 / 补钙 | 功能或营养强化声称 |
| 减肥 / 控卡 | 保健功能声称 |
| 营养均衡 | 可能构成营养声称，需谨慎 |

### 1.3 可以说什么

| ✅ 可以说 | 说明 |
|---|---|
| 配料表 | 客观信息 |
| 营养成分（每份含量） | 客观数据 |
| 规格、剂型 | 客观信息 |
| 食用方法 | 使用说明 |
| 口感、产地 | 客观描述 |
| 生产许可证号 | 可核实的资质信息 |

**界线**：**陈述事实可以说，描述作用不能说。**

#### 与 P004/P005 的关键差异

| | P004 乳清蛋白粉 | P005 大豆蛋白粉 | **P016 复合蛋白固体饮料** |
|---|---|---|---|
| 类别 | 保健食品 | 保健食品 | **普通食品** |
| 标识 | 食健备G... | 食健备G... | **SC...** |

| **能否说"增强免疫力"** | 能 | 能 | **绝对不能** |

**这是全套培训里最关键的一张表。** 三个产品都叫"蛋白"，外观都是罐装粉剂，但 P016 是普通食品。

#### 客户问"这个能不能增强免疫力"时

> 「这款是**普通食品**，生产许可证号是 SC11344010100123。
> 按照法规，普通食品**不能宣称任何保健功能**，所以我不能说它能否增强免疫力。
> 我可以告诉您它的客观信息：配料是大豆分离蛋白、乳清蛋白粉和麦芽糊精，每份 20g 含蛋白质 12g。
> 您可以自己判断需不需要。」

#### 常见错误（新人必犯）

| ❌ 常见错误说法 | 问题 |
|---|---|
| 「这个和那个蛋白粉差不多，都有助于增强免疫力」 | **把普通食品当保健食品讲功能** |
| 「这个便宜点，效果差一点」 | "效果"属功能暗示 |
| 「这个也含蛋白质，能补充营养」 | "补充营养"可能构成营养声称 |
| 「这个适合体弱的人」 | 暗示调节功能 |

### 产品二：康源牌胶原蛋白肽饮品（P017）

#### 基础信息

| 字段 | 内容 |
|---|---|
| 产品编号 | P017 |
| **产品类别** | **普通食品** |
| **生产许可证** | **SC11344010100124** |
| 剂型/规格 | 口服液，50ml/瓶 × 10 瓶 |
| 配料 | 水、鱼胶原蛋白肽、果葡糖浆、柠檬酸 |
| 建议零售价 | 268 元 |

#### 这是一个高风险品类

**胶原蛋白类产品是整个行业里最容易被说成"美容功效"的品类。**

| ❌ 绝对不能说的 | 为什么 |
|---|---|
| 改善皮肤弹性 | 保健功能声称 |
| 抗衰老 / 延缓衰老 | 保健功能声称 |
| 补充胶原蛋白，减少皱纹 | 功能暗示 |
| 让皮肤变好 | 功能暗示 |
| 美容养颜 | 功效声称 |

#### 可以说的话

> 「这款是普通食品，生产许可证号 SC11344010100124。
> 配料是水、鱼胶原蛋白肽、果葡糖浆和柠檬酸，每瓶 50ml。
> 口感是酸甜的，建议每天 1 瓶。
> 需要说明的是，普通食品不能宣称任何保健功能，所以我不能说它对皮肤有什么作用。」

**如果客户直接问"这个是不是能美容"**：

> 「这个我不能说。它是普通食品，法规不允许普通食品宣称任何保健功能。
> 如果您关心皮肤状态，我建议从作息、饮水、防晒这些方面入手，这些是有明确依据的。」

**这个回答的价值**：既守住了边界，又没有让客户空手（给了有依据的建议）。

#### 特殊情况：枸杞是药食同源物质

**这是最容易搞混的一点**：

| 情形 | 能否声称功能 |
|---|---|
| 枸杞作为**中药材**使用（中医处方） | 可以按中医理论使用 |
| 枸杞作为**保健食品原料**（有蓝帽子） | 可以声称批准的保健功能 |
| **枸杞作为普通食品销售（本产品）** | **不能作任何功能声称** |

**关键理解**：**同一个原料，销售形态不同，限制就不同。**

| ❌ | 为什么 |
|---|---|
| 养肝明目 | 中医功效声称 |
| 补肾益精 | 中医功效声称 |
| 提高免疫力 | 保健功能声称 |
| 抗疲劳 | 保健功能声称 |
| 宁夏枸杞自古入药 | 借"药"暗示功效 |

> 「这款是普通食品，生产许可证号 SC11344010100125。
> 配料就是枸杞和水，没有添加糖。
> 每袋 30ml，可以直接喝，也可以兑水。
> 关于功效，普通食品不能宣称，我只能告诉您配料信息。」

| 配料 | 大豆蛋白、膳食纤维、维生素预混料、甜味剂 |
| 建议零售价 | 218 元 |

#### 这个产品的特殊风险

**"代餐"这个词本身就有暗示性**，客户会自然联想到"减肥"。

| ❌ 绝对不能说 | 为什么 |
|---|---|
| 减肥 / 瘦身 / 控卡 | 保健功能声称 |
| 代替正餐减肥 | 功能暗示 + 可能影响健康 |
| 营养均衡，可完全替代正餐 | 营养声称 + 误导 |
| 低卡，吃了不长胖 | 功能暗示 |

#### 可以说的话

> 「这款是普通食品，配料是大豆蛋白、膳食纤维、维生素预混料和甜味剂。
> 每份的热量和营养成分在包装上有标注，您可以看一下。
> 需要说明的是，普通食品不能宣称保健功能，我不能说它有减肥作用。
> 另外我不建议完全用它代替正餐，具体怎么吃，建议咨询营养专业人员。」

**最后一句很重要**：代餐产品如果被用来完全替代正餐，可能造成营养不均衡。**提示不要完全替代**，是负责任的做法。

## 第四章 怎么跟客户解释"为什么不能说"

客户会不理解："别家都说有功效，你们为什么不说？"

### 4.1 标准解释

> 「因为这是法规要求。普通食品不允许宣称任何保健功能，说了就是违规宣传。
> 我们不说，不是产品不好，而是不能给您不准确的承诺。
> 如果您需要明确功能的产品，可以看我们的保健食品，那些是有批准文号和批准功能的。」

**这个回答的三个作用**：
1. 解释原因（法规要求，不是我保守）
2. 消除疑虑（不是产品不好）
3. 给出路径（有需求可以看保健食品）

### 4.2 一个必须避免的回答

> ❌「其实这个也有那个效果，只是我们不能说」

**这句话比直接说功效更危险**，因为它是"暗示 + 承认"的复合违规。

## 第五章 最容易犯的三种错误

### 错误一：把普通食品当保健食品讲

| 场景 | 表现 |
|---|---|
| 客户问 P016 能不能增强免疫力 | 答「可以的，含蛋白质」 |
| 后果 | 直接构成虚假宣传 |

### 错误二：用"效果"代替"功效"

| 场景 | 表现 |
|---|---|
| 客户问 P017 有没有用 | 答「效果因人而异」 |
| 问题 | 「效果」这个词本身就承认了有功效，属暗示 |

**正确说法**：「这款是普通食品，我不能说它有什么功效。」

### 错误三：用"原料功效"绕过"产品功效"

| 场景 | 表现 |
|---|---|
| 客户问 P018 枸杞原浆 | 答「枸杞养肝明目，这个是纯枸杞」 |
| 问题 | 通过讲原料功效绕过产品限制，仍属违规 |

**正确说法**：「配料是枸杞和水。关于功效，普通食品不能宣称，我只能告诉您配料信息。」
