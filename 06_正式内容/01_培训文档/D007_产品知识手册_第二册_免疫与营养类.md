## 本品类客户画像

这个品类里有两种完全不同的客户，处理方式差别很大：

| 类型 | 特征 | 你的重点 |
|---|---|---|
| **A 型：确实有缺口** | 老年人食欲差、术后恢复、严格素食、食量小 | 确认缺口 → 给方案（食物优先） |
| **B 型：以为需要** | 想增强抵抗力、觉得自己"虚"、健身增肌 | **先确认是否真的不足**，多数人不需要 |

**B 型占大多数**，也是最容易过度推荐的类型。

## 产品一：康源牌乳清蛋白粉（P004）

### 一、基础信息

| 字段 | 内容 |
|---|---|
| 产品编号 | P004 |
| **产品类别** | **保健食品** |
| **批准文号** | 食健备G202544000124 |
| 剂型 | 粉剂 |
| 规格 | 400g/罐（约 20 份，每份 20g） |
| 建议零售价 | 428 元 |

### 二、配料与成分

| 项 | 内容 |
|---|---|
| 配料表 | 乳清蛋白粉、麦芽糊精 |
| **标志性成分** | 每份（20g）含蛋白质 **15g** |
| 蛋白质含量占比 | 约 75% |

### 三、批准功能与人群

| 字段 | 内容 |
|---|---|
| **批准保健功能** | **有助于增强免疫力** |
| 适宜人群 | **因蛋白质摄入不足而致免疫低下的成人** |
| **不适宜人群** | 少年儿童 |
| **注意事项** | ①**无明显缺乏蛋白质的人群不推荐食用**<br>②**动物蛋白过敏者不宜使用**<br>③**肾功能不全者慎用**<br>④孕妇、乳母建议咨询临床医生或营养专业人员 |
| 食用方法 | 每日 1–2 次，每次 1 份（20g），温水冲调 |
| 每日用量上限 | 蛋白质 6–25g（成人每日蛋白质总量建议 60g） |

### 四、高危禁忌场景（必须背）

| # | 客户说了什么 | 风险 | 你该怎么做 |
|---|---|---|---|
| **1** | **「我肾不太好 / 肾功能不全」** | **最高危** | **建议咨询医生，不给具体用量** |
| **2** | 「我对牛奶 / 乳制品过敏」 | 过敏风险 | 改用大豆分离蛋白（P005） |
| **3** | 「我乳糖不耐受」 | 可能不适 | 说明可少量尝试，或选大豆蛋白 |
| **4** | 「给孩子吃」 | 明确不适宜 | 少年儿童是不适宜人群 |
| **5** | 「我平时吃得很正常，就是想补补」 | **可能无必要** | **先确认是否真的摄入不足** |

**第 1 条和第 5 条是这个产品最需要把握的两条。**

- 第 1 条：肾功能不全者高蛋白摄入会加重负担，**绝不给具体用量建议**
- 第 5 条：**多数人不需要**，这是"不该推"的典型场景

### 五、推荐的正确流程（重要）

```
① 先算：客户一天大概摄入多少蛋白质？
     ↓
② 判断：是否低于需要量？
     ↓
   不足 → ③ 先看食物能否补上
              ↓
         能 → 给食物方案（不推产品）
         不能 → ④ 才谈产品
   不缺 → 明确告知"您目前不需要补充"
```

**怎么估算蛋白质摄入**（不用精确，够判断就行）：

| 食物 | 蛋白质含量 |
|---|---|
| 1 个鸡蛋（约 50g） | 约 7g |
| 250ml 牛奶 | 约 8g |
| 100g 瘦肉 | 约 20g |
| 100g 鱼虾 | 约 17g |
| 100g 豆腐（北） | 约 9g |
| 1 碗米饭 | 约 4g |

**成人每日推荐量**：男约 65g，女约 55g。

**举例**：如果客户早餐 1 个蛋 + 1 杯奶（15g）、午餐 100g 肉（20g）+ 米饭（4g）、晚餐 100g 鱼（17g）+ 米饭（4g），合计约 60g，**已经够了，不需要补充蛋白粉**。

### 六、客户最常问的四个问题

**Q1：我免疫力差，吃这个有用吗？**

> 「这款批准的功能是『有助于增强免疫力』，适宜人群是『因蛋白质摄入不足而致免疫低下的成人』。
> 所以要先看您是不是蛋白质摄入不足。方便问一下您平时三餐大概吃什么吗？
> 如果摄入是够的，那这款对您帮助不大，我建议您从其他方面找原因，比如睡眠、作息。」

**Q2：我健身，需要吃蛋白粉吗？**

> 「这款是保健食品，适宜人群是蛋白质摄入不足的成人，批准功能是增强免疫力。
> **健身增肌不是它的批准功能**，我不能说它对增肌有帮助。
> 如果您是健身需要，建议咨询专业的运动营养师或教练。」

**这个回答很关键**：健身增肌是客户的需求，但不是这款产品的批准功能，不能顺着说。

**Q3：吃多了会怎么样？**

> 「每日蛋白质补充量建议在 6–25g，不要超过。而且要算上您平时饮食里的蛋白质，成人每天蛋白质总量建议 60g 左右。
> 长期大量摄入蛋白质会增加肾脏负担，所以不建议超量。」

**Q4：可以长期吃吗？**

> 「如果您确实存在蛋白质摄入不足，可以按说明长期食用。
> 但如果饮食已经能满足，就不建议长期依赖补充剂，还是以正常饮食为主。」

### 四、乳清蛋白 vs 大豆蛋白：怎么选

**这是本品类最重要的一张对比表。**

| 维度 | 乳清蛋白（P004） | 大豆蛋白（P005） |
|---|---|---|
| 来源 | 动物（牛奶） | 植物（大豆） |
| 每份蛋白质 | 15g | 16g |
| **过敏风险** | 牛奶蛋白过敏者不可用 | 大豆过敏者不可用 |
| **乳糖不耐受** | 可能不适 | **适合**（无乳糖） |
| **素食者** | 不适合（动物来源） | **适合** |
| 价格 | 428 元 | 268 元 |
| 批准功能 | 相同 | 相同 |

**选择逻辑**：

```
客户能喝牛奶吗？
  ├─ 能 → 乳清蛋白（P004）
  └─ 不能
      ├─ 乳糖不耐受 → 大豆蛋白（P005）
      ├─ 牛奶蛋白过敏 → 大豆蛋白（P005）
      └─ 素食 → 大豆蛋白（P005）
```

**这个判断是必须做的**，否则可能出现客户喝了乳清蛋白拉肚子、觉得产品有问题的情况。

## 本品类推荐前必须问的三件事

| # | 必须确认 | 为什么 |
|---|---|---|
| **1** | **平时三餐大概吃什么** | 判断是否真的蛋白质/营养不足 |
| **2** | **有无食物过敏**（牛奶、大豆、海鲜、其他） | 决定选乳清还是大豆 |

**第 3 条是最容易被忽略也最危险的。** 「我肾不太好」这句话，客户可能随口一提，但你必须停下来。

### 参考答案

**1.**

**因蛋白质摄入不足而致免疫低下的成人。**

注意这个表述很严格——不是"所有人"，而是"蛋白质摄入不足"的成人。

**2.**

> 这款产品的注意事项里明确写了「肾功能不全者慎用」。
> 您说肾不太好，具体是什么情况？如果确实是肾功能有问题，**这种情况建议您先咨询医生，看能不能吃、能吃多少，我这边不能给具体用量建议。**

要点：**不给用量 + 建议医生**。绝对不能算"你每天吃一勺就行"。

**3.**

**推荐大豆分离蛋白（P005）。**

理由：乳清蛋白来自牛奶，牛奶蛋白过敏者不宜使用。大豆分离蛋白是植物来源，适合牛奶蛋白过敏、乳糖不耐受和素食人群。

**4.**

> 这款产品的适宜人群是「因蛋白质摄入不足而致免疫低下的成人」，批准功能是「有助于增强免疫力」。
> **健身增肌不是它的批准功能**，我不能说它对增肌有帮助。
> 如果您是健身需要，建议咨询专业的运动营养师或教练。

要点：不能顺着客户的需求说"对增肌有帮助"，因为超出批准功能。

**5.**

> 两款都是保健食品，批准功能都是「有助于增强免疫力」，适宜人群都是免疫力低下者。
> 区别主要在形态：孢子粉是粉剂，需要冲服；孢子油是软胶囊，服用和携带方便一些。价格也有差别。
> 您按自己的使用习惯选就行，我不做哪个更好的评价。

要点：陈述客观差异 + 不做优劣评价。

**6.**

**基本不需要。**

粗略估算：1 个蛋约 7g + 1 杯奶约 8g + 午餐 100g 肉约 20g + 晚餐 100g 鱼约 17g = 约 52g，再加上主食和蔬菜中的蛋白质，总量接近 60g，**接近或达到成人每日推荐量**。

正确做法：告知客户摄入基本够，不需要额外补充，建议保持饮食均衡。
