> **文档编号**：D012 ｜ **类别**：业务流程 ｜ **权限**：内部
> **目标读者**：新入职健康顾问 ｜ **预计字数**：约 2,000 字
> **版本**：V1.0 ｜ **编制日期**：2026-10-21
> **审核重点**：字段是否符合公司实际记录系统、隐私条款是否符合法规

---

## 学习目标

学完本文档，你应当能够：

1. 正确填写客户记录的每个字段
2. 区分"客户自述"与"核实信息"
3. 说出五类绝对不能记入档案的内容
4. 正确处理他人索要客户信息的要求

---

## 第一章 为什么记录规范很重要

### 1.1 三个原因

| # | 原因 | 说明 |
|---|---|---|
| **1** | **服务连续性** | 同事接手时能快速了解情况 |
| **2** | **责任边界** | 记录了"客户自述"，出问题时有据可查 |
| **3** | **合规要求** | 客户健康信息属个人敏感信息，记录方式受法规约束 |

### 1.2 一个真实的风险场景

```
假设：
  顾问在档案里写"客户有糖尿病"
  后来客户出现低血糖，追溯时发现档案这么写
  但客户从来没被确诊过，只是自己说"血糖有点高"

后果：
  公司无法证明"这是客户自述"
  记录看起来像公司做了诊断
  → 公司承担诊断责任
```

**如果当时写的是**：

```
客户自述血糖偏高（自述，未提供检查报告，2026-10-21 到店）
```

**责任就清楚了**：公司记录的是客户的说法，不是公司的判断。

**这就是"标注自述"的意义。**

## 第二章 必填字段与填写规范

### 2.1 基础字段

| 字段 | 填写要求 | 示例 | 常见错误 |
|---|---|---|---|
| **到店时间** | 精确到分钟 | 2026-10-21 14:30 | 只写"10月21日" |
| **客户编号** | 系统自动生成 | C20261021001 | 手写导致重复 |
| **客户来源** | 自然到店 / 转介绍 / 线上预约 / 活动 | 转介绍（王女士介绍） | 写"朋友介绍"无法追溯 |
| **同行人** | 有无同行、关系 | 女儿陪同 | 漏填 |
| **接待人** | 你的姓名/工号 | 张三 / HR2025001 | 漏填 |

### 2.2 需求相关字段（**最关键**）

#### 字段一：主诉

| 要求 | 说明 |
|---|---|
| **原文记录** | 用客户的原话，不要转述成专业术语 |
| **必须标注"自述"** | 明确这是客户说的，不是核实的 |
| 记录时间 | 标注是哪次到店说的 |

**填写示例**：

```
❌ 错误：客户有高血脂
✅ 正确：客户自述"去年体检说血脂有点高"（自述，未提供报告，2026-10-21）

❌ 错误：客户睡眠障碍
✅ 正确：客户自述"躺下两三个小时睡不着，得刷手机到很晚"（自述，2026-10-21）

❌ 错误：客户骨质疏松
✅ 正确：客户自述"体检说骨密度偏低，医生让多补钙"（自述，未提供报告，2026-10-21）
```

**核心原则**：**记录"客户说了什么"，不记录"客户是什么病"。**

#### 字段二：用药情况

| 要求 | 说明 |
|---|---|
| 问"是否在服药"，**不问药名剂量** | 你不需要知道具体用药方案 |
| 如果客户主动说了药名，可以记 | 但要标注"客户自述" |
| 记录是否规律服药 | 影响后续建议 |

**填写示例**：

```
✅ 正确：客户自述在吃降压药（未说具体药名，未说剂量），每日规律服用（自述，2026-10-21）

✅ 正确：客户自述在吃阿司匹林（客户主动说明，未核实）（2026-10-21）

❌ 错误：客户在吃氨氯地平 5mg 每日一次
   ↑ 这是治疗方案，你不该追问，也不该记录这么细
```

**注意**：如果客户**主动**说了药名，记下来是合理的（因为涉及安全判断）。但**不要主动追问剂量和方案**。

#### 字段三：过敏史

| 要求 | 说明 |
|---|---|
| 具体名称 | 不要写"过敏体质" |
| 反应类型（如客户说了） | 起疹子、腹泻等 |
| 是否经检测 | 区分自述与检测确认 |

**填写示例**：

```
✅ 正确：客户自述吃虾后皮肤起疹子（自述，未做过敏原检测，2026-10-21）

✅ 正确：客户自述对牛奶过敏，喝奶后腹胀腹泻（自述，2026-10-21）

❌ 错误：客户海鲜过敏
   ↑ 太笼统，"海鲜"范围太大，且没标自述

❌ 错误：客户过敏体质
   ↑ 无法据此判断安全性
```

#### 字段四：生活方式

| 项 | 记录内容 |
|---|---|
| 作息 | 入睡时间、起床时间、睡眠时长 |
| 饮食 | 三餐规律性、主要食物、有无忌口 |
| 运动 | 类型、频率、时长 |
| 烟酒 | 有无、频次 |

**填写示例**：

```
作息：通常 23:30–24:00 入睡，7:00 起床，睡前刷手机约 1 小时（自述）
饮食：早餐常不吃，午晚餐正常；每天喝奶约 200ml（自述）
运动：基本无规律运动，日均步数约 3000（自述）
烟酒：不吸烟，偶尔饮酒（每月 1–2 次）（自述）
```

### 2.3 沟通记录字段

| 字段 | 内容 |
|---|---|
| **沟通要点** | 客户关注什么、你说了什么、客户反应 |
| **已说明事项** | 是否说明了产品类别、不适宜人群、警示语 |
| **客户异议** | 客户提出的顾虑及你的回应 |
| **后续安排** | 明确下一步动作和时间 |

**填写示例**：

```
沟通要点：
- 客户主要关注血脂，对价格敏感
- 已说明 P001 鱼油是保健食品，批准功能为"有助于维持血脂健康水平"，
  并说明了"不是药物，不能代替药物治疗"警示语
- 已说明不适宜人群（出血倾向者、肝功能不全、海产品过敏、孕妇乳母儿童）
- 客户表示在吃阿司匹林，已建议咨询医生
- 客户对价格有顾虑，已说明日均成本约 20 元

后续安排：
- 建议客户先咨询医生确认能否食用鱼油
- 3 天后（10-24）电话回访
```

## 第三章 绝对不能记入档案的六类内容

### 3.1 六类禁止内容

| # | 不能记 | 原因 | 正确做法 |
|---|---|---|---|
| **1** | **诊断性结论** | 你不是医师 | 记客户自述 |
| **2** | **具体检查数值**（如空腹血糖 7.8） | 属医疗数据，且你无权解读 | 记"客户自述血糖偏高" |
| **3** | **用药方案**（药名+剂量+频次） | 属治疗方案 | 记"客户自述在服药" |
| **4** | **主观评价**（如"客户很难沟通"） | 不专业，且有风险 | 记客观事实 |
| **5** | **与健康无关的隐私**（收入、家庭矛盾） | 无必要且涉侵权 | 不记录 |
| **6** | **他人健康信息**（客户的家人） | 未经本人同意 | 不记录 |

### 3.2 逐条说明

**第 1 条：诊断性结论**

```
❌ 客户患有高血压、糖尿病
❌ 客户属于肥胖
✅ 客户自述血压偏高、血糖偏高（自述，2026-10-21）
```

**第 2 条：具体检查数值**

```
❌ 空腹血糖 7.8 mmol/L，糖化血红蛋白 6.8%
✅ 客户自述血糖偏高，提到"医生说要注意"（自述，未提供报告）

为什么？因为记录数值意味着你在做数据追踪，但你无权解读这些数据。
```

**第 3 条：用药方案**

```
❌ 长期服用氨氯地平 5mg qd
✅ 客户自述在吃降压药，规律服用（自述）
```

**第 4 条：主观评价**

```
❌ 客户很难沟通，一直砍价，态度不好
✅ 客户对价格较敏感，多次询问是否有优惠（客观描述）
```

**第 5 条：无关隐私**

```
❌ 客户月收入约 8000 元，家里有两个孩子要养
✅ （不记录）
```

**第 6 条：他人信息**

```
❌ 客户母亲有糖尿病，父亲有高血压
✅ 客户提到家人有相关情况（如需记录，应另行说明用途）

注意：家人的健康信息属于第三方的个人信息，未经本人同意不应记录。
```

## 第四章 客户信息保密

### 4.1 三个场景的标准处理

#### 场景一：同事来问

**同事**：「昨天你接待的那个 XX 客户什么情况？」

| | 做法 |
|---|---|
| ❌ | 直接告知全部信息 |
| ❌ | 说"大概情况"但透露健康信息 |
| ✅ | 「客户信息属于隐私，我不方便透露。如果是工作需要，请让主管安排，我会配合。」 |

**为什么"说大概情况"也不行**：健康状况本身就是敏感信息，说"那位血脂高的客户"已经泄露了。

#### 场景二：客户家属来问

**家属**：「我妈上次来你们这测了什么？结果怎么样？」

| | 做法 |
|---|---|
| ❌ | 直接告知 |
| ✅ | 「需要客户本人同意，或者有她本人在场，我才能提供信息。」 |
| ✅ | 「如果她本人不方便，可以让她本人联系我们。」 |

**注意**：即使是直系亲属，未经本人同意也不能透露。

#### 场景三：客户要求查看自己的记录

| | 做法 |
|---|---|
| ✅ | 客户有权查看自己的信息，可以协助查询 |
| ✅ | 如果客户要求更正，按流程提交 |
| ✅ | 如果客户要求删除，按公司规定处理并记录 |

**这是客户的正当权利，不能拒绝。**

### 4.2 保密的三条底线

| # | 底线 |
|---|---|
| 1 | 不在公共区域谈论客户信息（包括店内、微信群） |
| 2 | 不把客户记录带出工作场所（包括拍照、截图） |
| 3 | 不用个人设备存储客户信息 |

## 第五章 记录质量的四个标准

### 5.1 四个标准

| 标准 | 含义 | 检查方法 |
|---|---|---|
| **完整** | 必填字段无空白 | 提交前逐项检查 |
| **准确** | 内容与事实一致 | 客户原话 vs 你的转述 |
| **及时** | 当天完成 | 不留到第二天 |
| **规范** | 格式统一、标注清晰 | 自述必须标注 |

### 5.2 提交前自检清单

```
□ 到店时间精确到分钟？
□ 客户来源具体（不是"朋友介绍"）？
□ 主诉是否用原话 + 标注"自述"？
□ 用药情况是否记录（含"未服药"也要写）？
□ 过敏史是否具体到食物/药物名称？
□ 是否有诊断性结论？（有则删除）
□ 是否记录了具体检查数值？（有则改为"自述"）
□ 是否记录了用药剂量？（有则删除）
□ 是否有主观评价？（有则改客观描述）
□ 后续安排是否明确到日期？
```

## 第六章 自测题

**1. 客户说「我血糖有点高，医生说要控制」，正确的记录方式是什么？以下哪个对？**
A. 客户患有糖尿病
B. 客户空腹血糖偏高
C. 客户自述"血糖有点高，医生说要控制"（自述，未提供报告，2026-10-21）

**2. 以下哪些不能记入客户档案？（多选）**
A. 客户自述在吃降压药
B. 客户空腹血糖 7.8 mmol/L
C. 客户月收入 8000 元
D. 客户自述吃虾后起疹子
E. 客户很难沟通，一直砍价
F. 客户母亲有糖尿病

**3. 同事问你「昨天那个血脂高的客户后来买了吗」，你该怎么回答？**

**4. 客户的女儿来问「我妈上次测的结果怎么样」，你该怎么回应？**

**5. 为什么"标注自述"这么重要？**

---

### 参考答案

**1. C**

- A 是诊断性结论，你无权做
- B 暗示了具体指标状况，且没标自述
- **C 正确**：原文记录 + 标注自述 + 记录时间

**2. B、C、E、F**

- A 可以记（标注自述即可）
- **B 不能记**（具体检查数值，属医疗数据）
- **C 不能记**（与健康无关的隐私）
- D 可以记（过敏史是必需信息）
- **E 不能记**（主观评价）
- **F 不能记**（他人健康信息）

**3.**

> 客户信息属于隐私，我不方便说。如果是工作需要，可以让主管安排，我会配合。

**注意**：连"那位血脂高的客户"这种描述都不能用，因为已经泄露了健康信息。

**4.**

> 需要客户本人同意，或者她本人在场，我才能提供信息。
> 如果阿姨不方便来，可以让她本人联系我，或者您下次陪她一起来。

**注意**：即使是直系亲属，未经本人同意也不能透露。

**5.**

**因为它划清了责任边界。**

不标自述，档案里的"客户有糖尿病"看起来像公司做的诊断。一旦出问题，公司要承担诊断责任。

标了自述，就明确是"客户这么说的"，公司只是记录者。

**这是保护客户，也是保护公司和你自己。**
