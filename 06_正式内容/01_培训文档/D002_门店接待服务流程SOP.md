> **文档编号**：D002 ｜ **类别**：业务流程 ｜ **权限**：内部

---

## 学习目标

学完本文档，你应当能够：

1. 完整说出接待五步流程及各步时长
2. 说出每步的必做动作和必说内容
3. 说出五个禁止行为
4. 处理四种常见异议而不越界
5. 正确填写客户记录

---

## 流程总览

```
① 迎宾与初步沟通  (1–3 分钟)
        ↓
② 需求了解        (5–8 分钟)  ← 最重要
        ↓
③ 方案说明        (10–15 分钟)
        ↓
④ 异议处理        (视情况)
        ↓
⑤ 记录与跟进      (3–5 分钟)
```

**总时长参考**：首次到店客户约 20–30 分钟；老客户复访可缩短至 10–15 分钟。

**顺序不能调整**：
- 方案说明必须在需求了解之后（不了解情况就推荐，必然出错）
- 异议处理必须在方案说明之后（客户没听到方案，无从异议）

---

## 第一步 迎宾与初步沟通（1–3 分钟）

### 1.1 必做动作

| # | 动作 | 说明 |
|---|---|---|
| 1 | **主动问候** | 「您好，欢迎光临」+ 微笑，不低头做别的事 |
| 2 | **判断是否首次到店** | 「您是第一次来吗？」决定后续话术 |
| 3 | **观察客户状态** | 面色、步态、有无明显不适 |
| 4 | **引导入座** | 久站不便的客户、老年客户优先引导就座 |
| 5 | **递水** | 一句「您先坐，我给您倒杯水」能显著降低防备 |

### 1.2 首次到店 vs 老客户

| | 首次到店 | 老客户复访 |
|---|---|---|
| 开场 | 「第一次来吗？我先了解一下您的情况」 | 「X 姐/先生，上次说的那个情况现在怎么样了？」 |
| 重点 | 建立信任，不急推产品 | 跟进上次效果，解决问题 |
| 时长 | 20–30 分钟 | 10–15 分钟 |

### 1.3 特殊情况处理

| 情况 | 处理 |
|---|---|
| 客户看起来不适（面色苍白、呼吸急促） | **先问「您还好吗？需要帮您叫医生吗？」**，不要先谈业务 |
| 客户说是来投诉的 | 立即请主管介入，自己不要辩解 |
| 客户说只是随便看看 | 不追着介绍，说「您先看看，有需要随时叫我」，保持距离 |
| 客户带着小孩/老人 | 先照顾同行人（椅子、水），客户会记住这个细节 |

### 1.4 这一步的禁区

- ❌ 不可以在客户刚进门时就问「您想买点什么」
- ❌ 不可以一上来就介绍产品
- ❌ 不可以对客户的穿着打扮做判断性评论

## 第二步 需求了解（5–8 分钟）

**这是整个流程最重要的一步。** 后面所有的建议质量，都取决于这一步问得够不够。

### 2.1 必问的四件事

| # | 问什么 | 为什么必问 | 怎么问（不要像审问） |
|---|---|---|---|
| **1** | **主要关注什么** | 决定后续方向 | 「您今天主要是想了解哪方面？」 |
| **2** | **是否在服药** | **直接影响安全** | 「您平时有在吃什么药或者保健品吗？」 |
| **3** | **有无食物过敏** | **直接影响安全** | 「有没有什么食物是吃了会不舒服的？」 |
| **4** | 平时的作息饮食运动 | 决定建议是否可行 | 「平时作息怎么样？运动多吗？」 |

**第 2、3 条是安全底线。** 漏问这两个，后面推荐什么都是盲目的。

### 2.2 二次追问（按客户回答深入）

**如果客户说「血脂有点高」**：

| 追问 | 目的 |
|---|---|
| 是体检发现的吗？大概多少还记得吗？ | 判断严重程度（不问病，只问数据） |
| 医生有没有说什么？ | 了解是否在医疗管理下 |
| 平时在吃药吗？ | **安全关键** |

**如果客户说「睡眠不好」**：

| 追问 | 目的 |
|---|---|
| 是睡不着，还是容易醒？ | 区分类型 |
| 大概多久了？ | 判断是偶发还是长期 |
| 平时几点睡？睡前会看手机吗？ | 找生活方式因素 |

**如果客户说「想减肥」**：

| 追问 | 目的 |
|---|---|
| 想减多少？有目标时间吗？ | 判断目标是否合理 |
| 平时三餐怎么吃？运动吗？ | 找可行切入点 |
| 之前试过什么方法？ | 避免重复失败方式 |

### 2.3 三个记录要点（当场记，不要事后回忆）

| 记什么 | 怎么记 |
|---|---|
| 客户主诉 | 原文记录，**加"自述"标注** |
| 用药情况 | 药名（客户说的原话）、是否规律 |
| 过敏史 | 具体食物/药物名称 |

**记录规范示例**：

```
❌ 错误：客户有糖尿病
✅ 正确：客户自述血糖偏高（自述，未提供检查报告，2026-10-15 到店）

❌ 错误：客户对海鲜过敏，不能吃鱼油
✅ 正确：客户自述吃虾会起疹子（自述，未做过敏原检测）
```

**为什么必须标"自述"**：自述不等于确诊。记录写成"客户有糖尿病"，看起来像诊断结论，一旦有纠纷，公司要承担责任。

### 2.4 这一步的禁区

- ❌ 不追问病情细节（「你这个糖尿病几年了」「空腹血糖多少」→ 属医疗问诊）
- ❌ 不问收入、住址、家庭矛盾等与健康无关的信息
- ❌ 不做任何"我看看你这个是什么问题"式的判断

## 第三步 方案说明（10–15 分钟）

### 3.1 说明顺序（不能颠倒）

```
① 先讲生活方式建议（食物、作息、运动）
        ↓
② 再讲公司可提供的服务（检测、评估、跟踪）
        ↓
③ 最后才讲产品（如果确实需要）
```

**为什么这个顺序**：先讲产品，客户会觉得你只想卖东西；先讲生活方式，客户会觉得你是真的在帮他。

### 3.2 涉及产品时的「五必说」

| # | 必说内容 | 为什么 |
|---|---|---|
| **1** | **产品类别**（保健食品 / 普通食品） | 客户有权知道 |
| **2** | **成分与批准功能原文** | 只能原文，不能改写 |
| **3** | **不适宜人群** | 安全底线 |
| **4** | 食用方法与用量 | 用量上限必须说 |
| **5** | **「保健食品不是药物，不能代替药物治疗疾病」** | 法规强制 |

**这五条缺一条都算不合格。** 特别是第 3 条和第 5 条，最容易漏。

### 3.3 标准话术模板

**介绍保健食品时**：

> 这款是**保健食品**，批准文号是 XXX，您可以到市场监管总局官网查。
> 它的主要成分是 XXX，每 X 含 XXX。
> 批准的功能是「**（原文）**」。
> 需要说明的是，它是保健食品，**不是药物，不能代替药物治疗疾病**。
> 不适宜人群是 XXX，如果您属于这几类，建议先咨询医生。
> 用法是每天 X 次、每次 X，**一天不要超过 X**。

**介绍普通食品时**：

> 这款是**普通食品**，生产许可证号 SC XXX。
> 配料是 XXX，每份含 XXX。
> 需要说明的是，普通食品**不能宣称任何保健功能**，我不能说它有什么功效。
> 但我可以告诉您它的营养成分，您自己判断需不需要。

**注意这个差别**：普通食品连"有助于"都不能说，只能陈述客观营养成分。

### 3.4 客户主动问产品时（必须如实答）

如果客户自己问「你们有这个吗」，**不能回避**：

| 客户问 | 你必须答 |
|---|---|
| 有没有这个产品 | 明确有 / 没有 + 产品名 |
| 含什么成分 | 配料 + 标志性成分含量 |
| 什么人不能吃 | 不适宜人群完整清单 |
| 怎么吃 | 用法 + 每日上限 |

**不能说的话**：
- 「这个我不太清楚」
- 「您问医生吧」（产品信息不是医学判断）
- 「我们只做健康管理」（回避即失职）

**能说的话**（当问题超出产品信息时）：
- 「这个需要医生判断」（涉及疾病、用药、特殊人群）
- 「建议您带报告去医院复查」（涉及诊断）

**界线**：**说明书上有的，必须答；说明书上没有的，可以说需要医生判断。**

## 第四步 异议处理

### 4.1 四步法

```
① 倾听，不打断
      ↓
② 认同感受，不认同错误认知
      ↓
③ 如实回应，不夸大不承诺
      ↓
④ 给出可执行的下一步
```

### 4.2 四种常见异议的标准处理

#### 异议一：「太贵了」

| | 内容 |
|---|---|
| ❌ 不能说 | 「别家更贵」「这个已经是最便宜的了」「现在有活动您赶紧买」 |
| ✅ 可以说 | 「这款是 X 粒装，按每天 2 粒算，日均成本大约 X 元。」<br>「如果您觉得预算有压力，我们还有规格小一点的，或者可以先从饮食调整入手。」 |
| **关键** | 说明**日均成本**（不是总价），且**提供更便宜的替代路径**（包括不买的路径） |

#### 异议二：「我朋友吃了说没用」

| | 内容 |
|---|---|
| ❌ 不能说 | 「那是他吃得不对」「我们这款不一样」「我们很多人都说有效」 |
| ✅ 可以说 | 「每个人的情况不一样，别人的体验不能直接套用。」<br>「保健食品是长期调理，不是药物，我不能承诺具体效果。」<br>「您朋友具体是什么情况？也许我们可以看看有没有更适合您的方式。」 |
| **关键** | **不承诺效果**，同时**不否定朋友的体验**（否定会让客户觉得你在攻击他朋友） |

#### 异议三：「你们是不是骗人的」

| | 内容 |
|---|---|
| ❌ 不能说 | 「怎么会呢，我们开了十几年了」「您不信可以走」 |
| ✅ 可以说 | 「您这个警惕是对的。这款产品的批准文号是 XXX，您可以到国家市场监督管理总局官网『特殊食品信息查询』里查，产品名称、生产企业、适宜人群都能对上。」<br>「普通食品是 SC 编号，没有蓝帽子的就不是保健食品，您也可以核对。」 |
| **关键** | **给出可验证的方法**，而不是让他相信你 |

#### 异议四：「别家比你们便宜」

| | 内容 |
|---|---|
| ❌ 不能说 | 「他们那个质量不行」「便宜没好货」 |
| ✅ 可以说 | 「这个我不方便比较别家。我只能说我们这款的参数：每粒含 XXX，规格是 X 粒装，批准文号是 XXX，您可以去查。」<br>「如果价格是您的主要考虑，也可以看看我们的 X 款，规格小一些。」 |
| **关键** | **不做贬低性比较**，只陈述自身客观参数 |

### 4.3 异议处理的三条纪律

| # | 纪律 | 违反后果 |
|---|---|---|
| 1 | **不贬低竞品、不贬低医院和药品** | 属违规行为 |
| 2 | **不承诺效果、不说"保证""一定"** | 虚假宣传风险 |
| 3 | **不用限时优惠制造紧迫感** | 不当施压 |

## 第五步 记录与跟进（3–5 分钟）

### 5.1 客户记录必填项

| 字段 | 说明 | 示例 |
|---|---|---|
| 到店时间 | 精确到分钟 | 2026-10-21 14:30 |
| 客户来源 | 自然到店 / 转介绍 / 线上预约 | 转介绍（X 姐介绍） |
| 主诉 | **原文 + 自述标注** | 自述「血脂有点高，去年体检查的」 |
| 用药情况 | 原话记录 | 自述在吃降压药（未说具体药名） |
| 过敏史 | 具体名称 | 自述吃虾起疹子 |
| 沟通要点 | 说了什么、客户关注什么 | 主要关注血脂，对价格敏感 |
| 后续安排 | 明确下一步 | 建议先做体脂检测，3 天后回访 |

### 5.2 记录的三条规范

| # | 规范 | 原因 |
|---|---|---|
| 1 | **自述内容必须标注"自述"** | 区分自述与核实信息 |
| 2 | **不写诊断性结论** | 写"客户有糖尿病"会构成诊断记录 |
| 3 | **当天完成，不留空白** | 隔天回忆必然遗漏 |

### 5.3 跟进规范

| 时机 | 动作 |
|---|---|
| 当天 | 记录完成，备注下次联系时间 |
| 3 天内 | 首次回访（问使用感受 / 是否还有疑问） |
| 1 周后 | 二次回访（问有没有坚持 / 遇到什么问题） |
| 1 个月后 | 效果回顾（如适用） |

**跟进不是催买。** 回访的第一句话应该是「用着还顺利吗，有没有什么问题」，而不是「要不要再买一盒」。

## 五个禁止行为（必须背下来）

| # | 禁止行为 | 为什么 |
|---|---|---|
| **1** | **以免费检测、义诊、讲座为名诱导消费** | 属于典型违规营销 |
| **2** | **宣称产品有治疗作用** | 违法宣传 |
| **3** | **替客户判断疾病、解读报告结论** | 越界执业 |
| **4** | **贬低医院、药品、其他品牌** | 违规且损害行业形象 |
| **5** | **以限时优惠、涨价、限量制造紧迫感** | 不当施压 |

### 补充：还有三个"看起来没问题但实际违规"的行为

| 行为 | 为什么违规 |
|---|---|
| 「很多人吃了都说好」 | 以他人经验为效果背书 |
| 「这个是医院同款」 | 无依据的权威暗示 |
| 「纯天然，没有副作用」 | 绝对化 + 暗示安全性 |

## 特殊场景处理

### 场景一：客户带体检报告来问

| 环节 | 做法 |
|---|---|
| 不可以做什么 | 不解读指标、不判断严重程度、不建议用药 |
| 可以做什么 | 说明我们不解读报告 → 建议带报告去医院复查 → 介绍可提供的日常健康管理服务 |
| 标准话术 | 「报告的具体指标需要医生来解读，我不能判断严不严重。」<br>「建议您带着报告去医院复查一下。」<br>「如果您想在日常饮食和作息上做些调整，这部分我可以帮您看看。」 |

### 场景二：客户在店内身体不适

| 情况 | 立即动作 |
|---|---|
| 胸闷、胸痛、呼吸困难 | **让客户静坐 + 立即拨打 120 + 通知店长** |
| 晕倒、意识不清 | **拨打 120 + 不搬动客户 + 通知店长** |
| 轻微头晕、乏力 | 让客户坐下、递水、问是否需要就医 |

**三条铁律**：
1. **不判断**是什么问题
2. **不给药、不给吃的**（包括糖水）
3. **不拖延**，宁可叫了 120 结果是虚惊

### 场景三：客户情绪激动投诉

| 步骤 | 做法 |
|---|---|
| 1 | 请客户到安静区域，避免影响其他客户 |
| 2 | 倾听，不打断、不辩解 |
| 3 | **立即请主管介入**，你不要自行承诺任何处理方案 |
| 4 | 记录客户诉求原文 |

## 自测题

**1. 接待流程的正确顺序是？**

A. 迎宾 → 方案说明 → 需求了解 → 异议处理 → 记录
B. 迎宾 → 需求了解 → 方案说明 → 异议处理 → 记录
C. 需求了解 → 迎宾 → 异议处理 → 方案说明 → 记录
D. 迎宾 → 需求了解 → 异议处理 → 方案说明 → 记录

**2. 需求了解环节，必须问到的四件事是什么？其中哪两件直接关系安全？**

**3. 推荐产品的正确顺序是什么？为什么这个顺序重要？**

**4. 客户说「别家比你们便宜」，你应该怎么回应？**

**5. 客户拿着体检报告问「这个箭头向上的指标严重吗」，你应该怎么做？**

**6. 以下哪些属于禁止行为？（多选）**
A. 以免费检测为名诱导消费
B. 主动询问客户是否在服药
C. 说「很多人吃了都说好」
D. 说「这个是医院同款」
E. 记录客户的过敏史
F. 说「现在有活动，您赶紧买」

---

### 参考答案

**1. B**

**2.**

四件事：①主要关注什么 ②是否在服药 ③有无食物过敏 ④平时的作息饮食运动。
其中 **②是否在服药** 和 **③有无食物过敏** 直接关系安全。

**3.**

顺序：**先生活方式建议 → 再公司服务 → 最后才是产品**。

为什么重要：先讲产品，客户会觉得你只想卖东西；先讲生活方式，客户会觉得你在真正帮他。而且很多情况下，生活方式调整就能解决问题，根本不需要产品。

**4.**

> 这个我不方便比较别家。我只能说我们这款的参数：每粒含 XXX，规格是 X 粒装，批准文号是 XXX，您可以去官网查。
> 如果价格是您的主要考虑，也可以看看规格小一些的。

要点：不贬低竞品、只陈述自身客观参数、提供替代方案。

**5.**

> 报告的具体指标需要医生来解读，我不能判断严不严重。
