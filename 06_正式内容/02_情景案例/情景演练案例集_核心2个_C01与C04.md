# 情景演练案例集（核心 2 个：C01、C04）

> **用途**：MySQL 案例库 + 演练评阅 Agent 的判定依据
> **说明**：本文件为 C01、C04 两个核心案例的完整版（含多份答卷评分示例）；其余 14 个见 `情景演练案例集_14个.md`
> **选例理由**：C01 是最基础的常规场景，C04 是风险最高的红线场景。这两个是全套案例的判定模板。

## 案例 C01：客户询问是否有鱼油

### 一、案例基本设定

| 字段 | 内容 |
|---|---|
| **case_id** | C01 |
| **案例标题** | 客户询问是否有鱼油 |
| **提问类型** | 产品信息询问（product_existence） |
| **难度** | ★☆☆（1/3） |
| **培训阶段** | S3 合规话术 |
| **预计时长** | 3–5 分钟 |
| **教学定位** | **基础场景**：练"客户主动问了必须如实答，且答得完整" |

### 二、客户人物设定

| 字段 | 内容 |
|---|---|
| 年龄 | 58 岁 |
| 性别 | 男 |
| 到场情境 | 首次到店，自己逛进来的，没有预约 |
| 已知情况 | 自述「去年体检说血脂有点高」 |
| 用药情况 | 未主动提及（需在对话中引出） |
| 性格设定 | 比较直接，问得比较快，不太有耐心听长解释 |
| 潜在顾虑 | 不太相信保健品，觉得"都是骗人的"（会在追问中体现） |

**设计意图**：这个客户有 3 个特点——①有明确需求（血脂高）②有信任障碍 ③可能正在服药。这三点合起来，正好逼着学员走完「回答→说明边界→提示风险→建立信任」的完整链路。

### 三、对话脚本

**系统扮演的客户开场**：

> 你们有鱼油吗？

**预设追问**（按学员回答质量动态选择）：

| # | 追问 | 触发条件 | 考察点 |
|---|---|---|---|
| F1 | 我体检说血脂有点高，吃这个管用吗？ | 学员报完产品信息后 | 功效边界 + 不承诺 |
| F2 | 要吃多久啊？ | 学员回答了 F1 | 不给疗程承诺 |
| F3 | 我平时还在吃降压药，能一起吃吗？ | 学员回答了 F2 | **禁忌识别** |
| F4 | 我怎么知道你们这个是不是真的 | 学员回答了 F3 | 信任建立（出示批准文号 + 查询方式） |
| F5 | 那你说我到底该不该吃 | 任意时机 | **不替客户判断** |

**F4 和 F5 是这个案例的两个难点**：
- F4 考的是"敢不敢让客户去查"，敢说"您可以到市场监管总局官网查这个文号"是专业性的体现
- F5 考的是"不越界"，不能说"您应该吃"，只能给信息让客户自己判断

### 四、必答要素清单

| ID | 要素 | 权重 | 类型 | 判定说明 |
|---|---|---|---|---|
| E1 | **明确回答有 / 没有** | 20 | **必须** | 出现「有」+ 产品名，或「没有」。不能是"好像有""我们产品挺多" |
| E2 | 给出产品名称 | 10 | 必须 | 出现具体产品名（如"鱼油软胶囊"） |
| E3 | 给出客观参数 | 15 | 必须 | 至少提到规格或含量之一（如"每粒含鱼油1000mg"或"60粒装"） |
| E4 | **说明产品类别与批准功能原文** | 20 | **必须** | 说清"是保健食品"+ 批准功能原句"有助于维持血脂健康水平" |
| E5 | **加强制警示语** | 15 | **必须** | 出现"不是药物，不能代替药物治疗疾病"或等价完整表述 |
| E6 | 提及服药时建议咨询医生 | 10 | 建议 | 客户提到降压药时给出建议 |
| E7 | 提及不适宜人群 | 10 | 建议 | 至少提到"出血倾向者"或"海产品过敏者"之一 |

**判定规则**：E1/E2/E3/E4/E5 为必需要素。**必需要素缺 2 项及以上 → 直接判定为回避，得 0 分。**

### 五、违禁表述检测

| 类型 | 正则模式 | 级别 | 说明 |
|---|---|---|---|
| 违规宣称 | `降血脂|降胆固醇|治疗|改善血脂|调节血脂` | **critical** | 属医疗术语或旧声称 |
| 效果承诺 | `肯定有效|保证|一定管用|很快见效|吃一个月就好` | high | 不能承诺效果 |
| 主动推销 | `要不要买|带两盒|现在有活动|买二送一|限时` | **critical** | B2 模式禁止 |
| 回避推诿 | `这个我不清楚|你问医生吧|我们只做健康管理` | high | 客户问产品必须答 |
| 替客户判断 | `你应该吃|你必须吃|你就吃这个` | high | 不能替客户做决定 |

### 六、参考答案

> 有的，是我们自己生产的鱼油软胶囊，每粒含鱼油 1000mg，其中 EPA+DHA 合计 300mg，一瓶 60 粒，建议每天 2 次、每次 2 粒，随餐吃。
>
> 需要说明一下，这是**保健食品**，批准的功能是「**有助于维持血脂（胆固醇/甘油三酯）健康水平**」。它不是药物，**不能代替药物治疗疾病**。
>
> 另外这款产品有几个不适宜人群：少年儿童、孕妇和哺乳期妈妈、有出血倾向或出血性疾病的人、肝功能不全的人，对海产品过敏的也不建议吃。
>
> 您刚才说血脂有点高，如果正在吃降压药或者其他药，建议先问一下医生，看能不能一起吃。
>
> 至于要不要吃、吃多久，我这边不能替您判断，得看您自己的情况和医生的意见。我能帮您的是把产品信息说清楚，另外在饮食上也可以给您一些建议，比如少吃动物油、多吃深海鱼，这些对血脂管理更直接。

> 有的，鱼油软胶囊，每粒1000mg。这是保健食品，功能是有助于维持血脂健康水平。不过我觉得您这个情况还是要看医生怎么说。

【要素覆盖】
✅ E1 明确回答有  ✅ E2 产品名称
⚠️ E3 客观参数（有含量，缺规格）

【判定建议】

**这个案例 C 是刻意设计的**：它展示了系统**能判什么、不能判什么**。系统不假装能判断"这句话是建议还是推诿"，而是明确交给主管。

## 案例 C04：客户询问能否停药

### 一、案例基本设定

| 字段 | 内容 |
|---|---|
| **case_id** | C04 |
| **案例标题** | 客户询问能否停药 |
| **提问类型** | 替代药物询问（drug_replacement） |
| **难度** | ★★★（3/3） |
| **培训阶段** | S3 合规话术 / S4 情景综合 |
| **预计时长** | 4–6 分钟 |
| **教学定位** | **最高风险红线**：这是唯一「答错会直接造成身体伤害」的类型 |

### 二、客户人物设定

| 字段 | 内容 |
|---|---|
| 年龄 | 66 岁 |
| 性别 | 女 |
| 到场情境 | 老客户带来朋友，自己顺便咨询 |
| 已知情况 | 高血压 8 年，长期服用氨氯地平 |
| 用药情况 | 明确说明"在吃降压药" |
| 性格设定 | 固执，相信"西药伤身"，有朋友"成功停药"的先例 |
| 潜在顾虑 | 担心长期吃药伤肝肾 |

**设计意图**：这个客户不是"不懂"，而是"有错误认知且有人证"。学员面临的不是知识问题，而是**在客户施压下能否守住底线**。

### 三、对话脚本

**客户开场**：

> 我吃这个是不是就能把降压药停了？我听说西药吃久了伤肾。

**预设追问（施压递进）**：

| # | 追问 | 施压方式 | 考察点 |
|---|---|---|---|
| F1 | 我朋友就是吃保健品把药停了的，现在血压挺正常 | **社会证明**（他人经验） | 能否坚持同一口径 |
| F2 | 少吃点药总归好一点吧，我减半行不行 | **折中妥协**（给台阶） | 能否拒绝"折中" |
| F3 | 那我要吃多久才能停 | **伪装成可协商** | 能否识别这是陷阱问题 |
| F4 | 你是不是不敢说啊，你们就是怕担责任 | **质疑动机** | 能否不动摇、不辩解 |

**这四问是递进的**：从"别人可以"到"少一点行不行"到"多久能停"到"你不敢说"。每一问都在给学员"松口"的机会。

**F4 是最难的一问**——客户质疑你的动机时，很容易为了证明自己不心虚而说出"其实也可以考虑"。

### 四、必答要素清单

| ID | 要素 | 权重 | 类型 | 判定说明 |
|---|---|---|---|---|
| E1 | **明确否定：不能停药** | 30 | **必须** | 必须有明确否定词（不能/不可以/不行/不可以停），不能是"看情况""建议不要"这种软化表述 |
| E2 | **说明保健食品不能代替药物** | 25 | **必须** | 说清产品性质与药物的区别 |
| E3 | **建议遵医嘱，用药调整由医生决定** | 25 | **必须** | 明确把决定权交给医生 |
| E4 | 对他人的经验做正确回应 | 10 | 建议 | 说明个体差异，不套用他人经验 |
| E5 | 引导到可提供的帮助 | 10 | 建议 | 回到饮食/生活方式，不空手 |

**关键规则**：E1/E2/E3 全部为**必须**，且 **E1 的表述强度单独判定**——出现任何软化词（"可能""也许""看情况""先试试"）即视为未达标。

### 五、违禁表述检测（全部 critical）

| 类型 | 正则模式 | 级别 | 说明 |
|---|---|---|---|
| **暗示可调整用药** | `可以试|可以少|可以考虑停|慢慢减|逐渐停|先停一段` | **critical** | 最严重 |
| **折中妥协** | `减半|少吃一点|隔天吃|先减量` | **critical** | 同样不可接受 |
| **以他人经验背书** | `我朋友|别人都|很多人都停药|有人停了也没事` | **critical** | 强化错误认知 |
| **贬低药物** | `西药伤肾|药有副作用|长期吃药不好|药比保健品毒` | **critical** | 附和客户错误认知 |
| **软化否定** | `看情况|因人而异|不一定|这个不好说` | **critical** | E1 未达标 |
| **给时间承诺** | `吃几个月就能停|一年左右|三个疗程` | **critical** | 变相承诺 |

**这个案例没有"轻微违规"的概念**——只要命中任何一条，就是一票否决。

### 六、参考答案

> **不可以。**
>
> 这个产品是保健食品，不是药物，不能代替药物治疗疾病，更不能替代您的降压药。
>
> 您提到西药伤肾，这个担心我理解，但降压药是医生根据您的血压情况开的。是否调整用药、怎么调整、能不能减量，必须由您的医生根据血压监测结果来判断，我这边不能给任何用药建议。
>
> 您说朋友吃保健品停了药，这个我不能替她判断，每个人的身体情况、用药方案都不一样，她的做法不一定适合您。而且如果自己停药，血压反弹的风险很大。
>
> 如果您想辅助管理，我可以在饮食和生活方式上给您一些建议，比如控制钠摄入、规律监测血压、保持适当运动。这些对血压管理确实有帮助。
>
> **但药一定不能自己停。**

### 七、评分示例

**答卷 A（正确，预计 100 分）**

> 不可以。这个是保健食品，不是药，不能代替药物治疗疾病，也不能替代您的降压药。要不要调整用药、能不能减量，得由医生根据您血压的情况来定，我这边不能给用药建议。您朋友的情况我不了解，每个人情况不一样，不建议照搬。饮食上我可以帮您看看，比如少盐、规律测血压。

| 要素 | 判定 |
|---|---|
| E1 明确否定 | ✅ 「不可以」 |
| E2 不能代替药物 | ✅ |
| E3 建议遵医嘱 | ✅ |
| E4 回应他人经验 | ✅ |
| E5 引导到帮助 | ✅ |
| 违禁 | 无 |

**答卷 B（致命错误，0 分）**

> 这个可以试试，很多人吃保健品慢慢就把药停了。您先减半试试，观察一段时间，血压稳定的话就可以考虑停。

| 判定 | 结果 |
|---|---|
| E1 | 🔴 **未达标**（"可以试试""可以考虑停"是暗示可停药） |
| 违禁命中 | 🔴 **3 处 critical**：可以试、很多人把药停了、先减半试试 |
| 结论 | **0 分，一票否决，必须重新培训** |

**摘要卡输出**：
```
【风险提示】
🔴 critical 「这个可以试试」— 暗示可调整用药
   定位：第1轮第1句
🔴 critical 「很多人吃保健品慢慢就把药停了」— 以他人经验背书
   定位：第1轮第1句
🔴 critical 「先减半试试」「就可以考虑停」— 折中妥协 + 暗示可停药
   定位：第1轮第2句

【要素覆盖】
🔴 E1 明确否定（未达标：表述为"可以试试"）
❌ E2 说明不能代替药物
❌ E3 建议遵医嘱
❌ E4 回应他人经验（反向强化了错误认知）
❌ E5 引导到帮助

【待人工确认】
无 —— 本案为 critical 级别，无需人工判断

【判定建议】
🔴 命中 3 处 critical 违规，E1 未达标
→ 强制结论：不合格，一票否决
→ 处理：重新培训 L3 合规话术线，加练 3 个替代药物类案例
```

**答卷 C（看似合理但有隐患，需人工判断，预计 60 分）**

> 这个我不能给您建议。您还是听医生的吧，药的事我真不懂。不过您要真想调理，我可以给您介绍点别的。

| 要素 | 判定 |
|---|---|
| E1 明确否定 | ❌ **未达标**——"不能给您建议"≠"不能停药"，方向错了 |
| E2 不能代替药物 | ❌ 没说 |
| E3 建议遵医嘱 | ⚠️ 说了"听医生的"，但没说明为什么 |
| E4 回应他人经验 | ❌ 未回应 |
| E5 引导到帮助 | ⚠️ "介绍点别的"含糊，且可能滑向推销 |

**摘要卡输出**：
```
【风险提示】
⚠️ critical 「这个我不能给您建议」— 拒绝回答，但未给出核心答案（不能停药）
   定位：第1轮第1句
⚠️ high 「我可以给您介绍点别的」— 可能滑向产品推荐，需结合后文判断
   定位：第1轮第2句

【要素覆盖】
❌ E1 核心答案缺失：客户问"能不能停药"，回答必须包含"不能停药"，
   本例只说了"不能给建议"，属答非所问
❌ E2  ❌ E4
⚠️ E3 提到看医生但未说明理由
⚠️ E5 引导方向含糊

【待人工确认】
1. 「我可以给您介绍点别的」— 若后续介绍的是产品，则构成回避+推销双重问题；
   若介绍的是饮食方案，则可接受。请主管结合完整对话判断。

【判定建议】
E1 未达标（核心答案缺失），但未命中明确违禁词
→ 建议结论：不合格（需重练），重点讲清"拒绝给建议"和"给出核心否定答案"的区别
```

**答卷 C 是最容易出现的错误**，比答卷 B 更隐蔽。学员以为自己守住了底线（"我不能给您建议"），实际上**客户最需要的那句"不能停药"根本没说出来**。

系统必须能识别这种"看起来谨慎、实际回避"的情况——这正是 B2 补充规范里说的**回避也是失职**。

| 维度 | C01 | C04 |
