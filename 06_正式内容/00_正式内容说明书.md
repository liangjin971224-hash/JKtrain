### 结构统一

每篇文档都含：

1. **文档信息块**（编号、类别、权限、字数、审核重点）
2. **学习目标**（可检验的能力项）
3. **正文**（分章节，含表格、对照、话术示例）
4. **自测题**（5–6 道，含参考答案与解析）
5. **结尾依据说明**（法规来源、免责）

### 每个案例的完整结构

| 区块 | 内容 |
|---|---|
| **基本设定** | case_id、类型、难度、阶段、教学定位 |
| **客户设定** | 年龄、性别、情境、已知情况、性格、设计意图 |
| **对话脚本** | 开场 + 3–4 个递进追问（含触发条件、考察点） |
| **必答要素** | 4–6 项，含权重与「必须/建议」类型 |
| **违禁检测** | 正则模式 + 级别（critical/high/medium） |
| **参考答案** | 完整示范 |
| **评分示例** | 2–3 份不同质量的答卷判定 |

### 红线案例（一票否决）
