## 1. 问题：检索已到顶，失分转移到生成侧

45 题答案 rubric（`eval_questions_v3.jsonl`）基线 39/45。6 道失分里：

- **4 道是生成侧**（gold 就在前 5）：`ev2-01`、`ev2-03`、`ev2-14`、`ev2-28`；
- 2 道是检索侧（`ev2-25`、`ev2-35`，gold 不在前 5，prompt 救不了）。

生成侧的四类问题正好对应四条规则：

| 题 | 失分 | 规则 |
|---|---|---|
| `ev2-01` | 写「缓解视疲劳」，目录原文是「缓解视觉疲劳」 | A 批准功能逐字使用原文 |
| `ev2-03` | 只说「减肥是旧表述」，没给规范替代 | B 指出禁用时给规范替代 |
| `ev2-14` | 没追问关键信息 | C 缺关键信息先问清 |
| `ev2-28` | 没落到配料表 | D 依据来源分级/落到条文 |

## 2. 设计：v2 / v3 双版本，默认先不动

`AnswerQuestionUseCase(prompt_variant=...)` + `settings.prompt_variant`（env `PROMPT_VARIANT`）：

- **v2**：现有八条硬约束；
- **v3**：八条 + 「回答前自检」四条（A 批准原文 / B 替代说法 / C 先问清 / D 来源分级）。
  自检块明确要求「只自检，不要把自检过程写进回答」。
- 未知版本回退 v2；流式与非流式共用 `_system_prompt()`，不会各用各的。
- 验收通过后默认改为 v3；`PROMPT_VARIANT=v2` 一行回滚。

## 3. 实测结果

### 3.1 主集：45 题 rubric（`p1c_prompt_v3_20261107_202504`）

| 口径 | v2（基线） | v3 | 变化 |
|---|---|---|---|
| rubric 通过 | 39/45（0.867） | **41/45（0.911）** | **+2** |
| 缺要点总数 | 7 | 6 | -1 |
| 禁用命中 | 0 | 0 | 0 |
| 拒答 | 0 | 0 | 0 |
| 平均答案字数 | 178 | 203 | +14% |
| P50 延迟 | 3.32s | 4.21s | +27%（含 LLM 波动） |

逐题翻转：**3 上** `ev2-01`（批准原文）、`ev2-03`（替代说法）、`ev2-14`（先问清）；
**1 下** `ev2-19`——回答写的是「大豆蛋白过敏」，rubric 期望「大豆过敏／植物蛋白过敏」，
属词形误报，非质量回退。McNemar p=0.625（n 小，不显著，看机制与方向）。

### 3.2 独立 held-out：两套 12 题（证据相同，只差 prompt）

两组题与主集**零问题重叠**。为排除检索差异，把题目自带 `references` 正文
作为 `fact_hints` 注入两臂，使 v2/v3 看到完全相同的材料（只比较 prompt）。

| 题集 | v2 通过 | v3 通过 | 禁用 v2→v3 | 拒答 v2→v3 |
|---|---|---|---|---|
| `heldout_questions`（12） | 9/12 | 9/12 | 1 → 0 | 1 → 0 |
| `heldout2_questions`（12） | 8/12 | **10/12** | 2 → 1 | 0 → 0 |
| **合计** | **17/24** | **19/24** | **3 → 1** | **1 → 0** |

翻转：5 上 / 3 下。3 个「下」逐题核对均为 rubric 词形误报——
`hq-10` 写「不得自行归因或下结论」而 rubric 要「不能直接下结论」；
`hq-11` 写「未列明」而 rubric 要「没有」；`h2-11` 写「不包含」而 rubric 要「没有」。

## 4. 决定

**v3 采纳为默认。** 依据：

1. 主集 +2、held-out 合计 +2，方向一致；
2. 禁用命中 3→1、拒答 1→0（合规与可用性同向改善）；
3. 所有「回退」逐题核对均为判分词形问题，没有实质质量损失；
4. 收益来自四条可解释的合规规则，不是对评测集的过拟合。

**代价**：答案更长（主集 +14%，held-out +9%~37%）、延迟约 +20~30%。
对培训助教场景可接受；若成本敏感，`PROMPT_VARIANT=v2` 回滚。
`ev2-25`/`ev2-35` 仍是检索窗口外，prompt 无法修复。
