## 2. D2：检索调试端点

`POST /api/ops/retrieval`（主管权限，复用 `miss_log_view`）

请求：

```json
{"query": "鱼油每天吃几粒", "collection": "health_training_docs", "top_k": 20}
```

响应：

```json
{
  "query": "...",
  "collection": "...",
  "intent": "产品功效",
  "weights": [0.5, 0.3, 0.2],
  "elapsed_ms": {"graph": 2, "vector": 120, "keyword": 8},
  "degraded": [],
  "paths": {
    "vector": [{"chunk_id": "...", "score": 0.72, "title": "...", "section": "..."}],
    "keyword": [{"chunk_id": "...", "score": 21.3, ...}],
    "sparse": [{"chunk_id": "...", "score": 0.31, ...}]
  },
  "fused": [{"chunk_id": "...", "fused_score": 0.016, "sources": ["vector","keyword"]}]
}
```

- **不调 LLM、不写库、不写未命中日志**；只走 `RetrieveUseCase`（含路径阈值/窗口构图）。
- `collection` 只允许配置里的四个库，默认 `coll_training`；`top_k` 1~50，`fused_limit` 固定 10。
- 主管权限：`require_feature("miss_log_view")`（与未命中清单一致）。
- 失败：query 为空 400；collection 非法 400；端口未就绪 503。

## 3. D3：运行指标

`GET /api/ops/metrics`（主管权限）

- **LLM**：`stats()`（各端点 success/failed）、`last_used`、`last_error`（主备切换可见）。
- **请求**：`answer_total / refused / guardrail_blocked / empty_answer` 计数；
  延迟 `p50 / p95`（最近 200 次，内存滚动窗口）。
- **检索**：可选的最近一次 retrieval 耗时（D2 记录）。
- **进程**：uptime、ready ports、pending ports。

实现：

- 新增 `application/services/ops_metrics.py`：`OpsMetrics`（线程安全；计数器 + 延迟 deque 200）。
- `Container.metrics` 单例；`ask.py` 在非流式 / 流式 `done` 后记录：
  `latency_ms / refused / guardrail_blocked(meta.blocked_rules) / empty_answer`。
- 不侵入 `AnswerQuestionUseCase`；只在接口层观测。
