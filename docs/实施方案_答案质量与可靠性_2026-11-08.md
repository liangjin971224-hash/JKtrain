## 2. A2：护栏否定句精度

### 设计

只在 `_COMPLIANT_PHRASES`（A 组，任何类别都合规）增加**产品否定治疗**短语：

```
"不是治疗", "不能治疗", "不能代替治疗", "不能代替药物治疗",
"不用于治疗", "不能用于治疗", "非治疗", "不是治疗药物", "不能作为治疗"
```

- 这些短语会被 `_strip_compliant` 整段挖掉，剩余文本再跑 DC-01；
- **不放行**「可以治疗」「治疗糖尿病」「根治」等肯定式；
- 不放行「不建议治疗」这类对**疾病**的建议（可能有害），只放行对**产品**的否定。

### 验收

- 正例（应放行）：「本品不是治疗药物，不能治疗疾病」「不能代替药物治疗疾病」
- 反例（应拦截）：「这个能治疗糖尿病」「可以治疗」「根治高血压」
- 单测覆盖在 `tests/test_domain/test_forbidden_claims.py`（正反例各 ≥4）。
- 用 45 题答案集重跑：`DC-01` 触发的重试次数应下降；禁用语命中不增加。

## 3. A3：空答案不变量

### 3.1 适配器层（首选）

`FallbackLanguageModel._try_all` 增加 `require_text=True`：

- `generate` 返回 `GenerationResult.text.strip() == ""` → 记为失败（"空正文"），
  主端点可重试，然后切备用；
- `generate_stream` 只把**非空白**增量算作「已产出」；全空白 → 视为该端点失败，切备用；
- `classify` 不受影响（返回值是标签字符串）。

### 3.2 用例层（兜底）

`AnswerQuestionUseCase.execute`：

- 重试用尽/部分保留后，若最终 `answer.strip()` 为空 → 不返回 `refused=False`，
  统一走 `BLOCKED_TEMPLATE` + `refused=True`；
- 流式：记录是否产出过非空白 text；若没有，`done` 事件标 `refused=True`，
  理由「模型未产出正文」。

### 3.3 参数

新增 `settings.llm_max_tokens: int = 2048`（env `LLM_MAX_TOKENS`），
`AnswerQuestionUseCase` 透传到 `generate` / `generate_stream`。
目的：给 DeepSeek 推理留足余量，避免 1024 被 reasoning 吃满。

### 验收

- 单测：空正文 → 切备；两端都空 → `LLMCallError`；用例空答案 → `refused=True`；
- E2E：DeepSeek 主用跑 10 题，空答案 0（若仍偶发，说明 max_tokens 还不够，再提）。

| `spurious_no_info` | 初稿说「资料里没有」，但关键词分 ≥ 阈值且有具体词重合 | 基于参考资料直接回答，先结论后依据 |
| `medical_escalation` | 问题涉及停药/同服/头晕/不适/赔偿等，初稿没有医生/就医/120 | 补「建议就医」或「遵医嘱」+ 上报/记录 |

### A4.4 A/B 门禁

3. 拒答不增加；
4. 空答案 0；
