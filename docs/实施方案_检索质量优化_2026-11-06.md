## 3. 风险登记册（执行视角）

| 风险 | 触发点 | 预案 |
|---|---|---|
| Codex 标注口径不稳（同 chunk 前后标注不一致） | 0.3 | 82 号工作包里附 few-shot 示例；83 号质检报告出一致率；<90% 重跑对应批次 |
| section 映射覆盖率 <60%（0.1→0.2 断链） | 0.2 | 策略 B 改为全量主力，策略 A 只保留 miss_log 部分 |
| rerank 在 CPU 上延迟超预算（>1s/次） | 1.1 | 实测数据决定：调小 candidate_k（20→10），或 rerank 仅在非流式链路启用 |
| 训练后 R@5 涨但答案级回退 | 2.7 | 按门禁不上线；检查难负例是否把模型带偏，调整配比重训 |
| 首轮训练不收敛/过拟合（样本 ~500 对偏小） | 2.3 | 降 epoch、加大 dropout；扩充生成问题到 3 问/chunk |
| 重建 collection 后漏跑 verify | 2.5 | SOP 固化：重建后必跑 `verify_v2.py`，条数 293/117/140/30 |
