# 实施方案：培训助教 Agent（只读版，2026-11-09）

> 上游：用户 2026-11-09 决策「先只读版 / 新 Agent 页 / 长任务异步」。
> 目标：把现有问答、图谱、演练评阅能力编排成可执行多步任务，而不是做通用聊天机器人。

## 1. 范围

### 做

- 只读工具：`kb_answer`、`graph_facts`、`my_drill_reviews`、`weakness_summary`。
- 规则优先的任务规划；每任务最多 4 次工具调用。
- LangGraph：`plan → act → synthesize → guardrail → respond`。
- `POST /api/agent/chat`；前端新增「Agent」页，展示执行计划/步骤/最终回答。
- 演练薄弱项 + 案例推荐（从现有案例库按能力项匹配）。

### 不做（明确）

- **不 Agent 化演练对话**：台词 100% 脚本化是红线。
- **不把合规判定交给 LLM**：要素/风险判定继续走规则。
- **不重写检索/护栏**：全部复用 `AnswerQuestionUseCase` 与 `OutputGuardrail`。
- **不单独交付 QaAgent 六节点图**：现有线性问答功能等价，任务级 Agent 图更有价值。
- 写工具（组卷/月报）后置到第二阶段；月报继续走异步任务队列。

## 2. 工具契约

| 工具 | 参数 | 权限 | 返回 |
|---|---|---|---|
| `kb_answer` | `question`, `collection?` | `ask` | `answer/refused/citations` |
| `graph_facts` | `product_id` 或 `alias` | `ask` | 产品事实（类别/批准功能/不适宜人群/用法） |
| `my_drill_reviews` | `days?`, `trainee_no?` | `drill` | 近 N 天评阅摘要；学员只能查自己 |
| `weakness_summary` | `days?`, `trainee_no?` | `drill` | 能力项得分、薄弱项、推荐案例 |

- 工具参数由各 handler 校验；Agent 不能写 SQL、不能任意调仓储。
- 身份从 token 取；`my_drill_reviews` 不接受非主管传他人工号。
- 每个工具 15s 超时；Agent 总预算 4 次工具调用。

## 3. 图与状态

```
plan（规则规划）
  → act（执行下一步工具）
  → act …（最多 4 步）
  → synthesize（确定性汇总，不额外调 LLM）
  → guardrail（OutputGuardrail 必经）
  → respond
```

- `AgentState`：question、identity、plan、cursor、observations、answer、refused、steps。
- 工具失败/超时：记录 step，继续下一步；全部失败 → 安全拒答。
- 汇总优先复用 `kb_answer` 的已护栏答案；结构化数据用固定模板，避免编造。
- 不引入 LLM 规划（v1 规则优先，零额外延迟、零幻觉）；复杂问法默认为 `kb_answer`。

## 4. API 与前端

- `POST /api/agent/chat`：`{question}` → `{answer, refused, plan, steps, citations}`。
- 设置 `AGENT_ENABLED`；本地 `.env` 打开，默认 false。
- 前端「Agent」tab：输入问题 → 展示计划（工具名/原因）与步骤（成功/耗时）→ 最终回答。
- 学员与主管都可用；主管的 `trainee_no` 参数可查他人，学员只能查自己。

## 5. 验收

1. 工具单测：权限、参数校验、超时、空数据、仓储异常。
2. 图单测：规则规划、最多 4 步、工具失败继续、全失败拒答、护栏拦截。
3. API：学员/主管 200；未登录 401；`AGENT_ENABLED=false` 404；跨用户查评阅 403。
4. 浏览器：KB 任务（鱼油功能）与演练薄弱项任务各跑一次，计划/步骤/回答可见。
5. 回归：全量 pytest + ci_gate；单轮 100 题基线不因 Agent 改变（Agent 独立入口）。

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 工具选错 | 规则命中优先；未知问题走 `kb_answer`；最多 4 步 |
| 跨用户数据 | 工具层按身份校验；`trainee_no` 仅主管可用；负例测试 |
| 结构化输出触发护栏 | 只输出计数/标签，不复述违规原文；护栏兜底 |
| 延迟 | 只读工具并行/串行可控；无额外 LLM 规划；KB 15s 超时 |
| 范围蔓延 | 写工具、演练对话 Agent 化不在本阶段 |
